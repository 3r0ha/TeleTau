# Кадры для анимации — что загрузить и что попросить

**Зачем.** Чтобы пчела моргала и махала крыльями, нужна вторая версия той же картинки, где изменено **только одно**: глаза закрыты или крылья в другом положении. Нейросеть хорошо правит готовую картинку, не трогая остальное. Из двух картинок я соберу анимацию.

**Как сделать каждый кадр** (одинаково для всех блоков ниже):
1. Открой Nano Banana и **прикрепи исходную картинку** из строки «Прикрепить» — это твой оригинал из `design/assets/incoming/`.
2. Вставь промпт из блока целиком.
3. Сохрани результат под именем из строки «Сохранить как» в ту же папку `design/assets/incoming/`.

**Если что-то сдвинулось:** другой поворот, размер, лишняя деталь — просто сгенерируй заново. Я проверю совпадение с оригиналом автоматически и скажу, какие кадры переделать.

Порядок — по пользе: первые 5 кадров уже дают живую пчелу на главных экранах. Остальные — по желанию.

## 1. `bee-idle-blink` — моргание
- **Прикрепить:** `design/assets/incoming/bee-idle.jpg`
- **Сохранить как:** `design/assets/incoming/bee-idle-blink.jpg`

```
Edit the attached image. Keep absolutely everything identical: the same character, pose, proportions, colors, framing, size and position in the frame, and the same plain pure white background. Do not move, resize, crop or redraw anything else. Change only one thing: the eyes are closed in a relaxed blink — each eye is replaced by a short soft downward-curved line in the same dark chocolate brown, exactly where the eye was; eyebrows, cheeks and mouth stay the same.
```

**Что я сделаю без новых картинок** (уже на тех, что есть): декорации тропы покачиваются, трамвай катается, рыба выпрыгивает. Тропа дорисовывается до текущего узла, текущий узел «дышит». Пчела плавает вверх-вниз. Ещё: капли мёда при верном ответе, счётчик мёда, огонь серии, блик на значке лиги. При системной настройке «Уменьшение движения» всё выключается.
