# Промпты для Nano Banana: вторая партия — «живой» продукт

Для показа эта партия **не обязательна**: экраны M2 работают на первой партии (`batch-1.md`, 38 файлов). Эти картинки делают продукт живее. Разделы идут по пользе для показа; внутри раздела — по порядку.

Всё как в первой партии:
- заголовок блока — имя файла;
- файлы класть в `design/assets/incoming/`;
- для картинок с пчелой **прикрепляй утверждённую `bee-idle` как референс**, для мест — любую утверждённую картинку места;
- фон белый, кроме `hero-landing`, `tg-bot-cover` и `place-*-hero`. Его уберёт `design/scripts/process-assets.mjs`.

Анимация — отдельный файл `batch-3-animation.md`.
