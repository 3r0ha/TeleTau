# Входящие ассеты

Сюда владелец кладёт картинки из нейросети (или векторизованные). Список, имена и требования — `docs/15-art-brief.md` §0.

После проверки (палитра, размеры, вес, согласованность серии) файлы обрабатываются скриптом `node design/scripts/process-assets.mjs [часть-имени]` и попадают в `design/assets/approved/` (WebP; иконки — ещё PNG 1024). В коде и прототипах используются только `approved/`.
