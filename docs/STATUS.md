## Где остановились

**Переименование в «ТелеТау» и доработка.** Продукт называется «ТелеТау» (теле — язык, тау — гора); домен `teletau.study` (сайт, `api.`, `console.`, Mini App — `/miniapp`). Внутренние имена: пакеты `@teletau/*`, `ru.teletau.app`, `TeleTau.xcodeproj` и модули `TeleTau*`, префиксы `--tt-`/`tt-`, базы и контейнеры `teletau*`, переменные `TELETAU_*`, QR-карточки `TT1`/`TP1` (векторы v2; контрольные суммы прежние). Резервная копия до переименования — в scratchpad сессии (`backup-rename/`). Новое: лендинг по образцу Duolingo с кнопкой «Скачать для Android» (`ANDROID_APK_URL`), награды (12, векторы `achievements/`; считает сервер) — на вебе, iOS и Android: блок в профиле, лист награды, экран «Новая награда!» / «Новые награды!» после урока (итог → серия → награда → лига), снимки в обеих темах, «Что в уроке» у учителя, сайт как приложение (манифест, офлайн-страница, страницы ошибок, превью ссылки), озвучка Lingua Libre; курс v7 — 35 записей (мин, һин, мәктәп, тау, эт — записи с подписью латиницей, слово кириллицей в `audio.word_ba` проверяется буква в букву, `scripts/lib/audio.mjs`) и «кесаҙна» (четверг) в уроке «Дни недели». Тема: по умолчанию светлая на всех каналах (системная тема не учитывается; Mini App — всегда светлая), тёмная — по тумблеру, нейтральная графитовая палитра (`docs/05`); тёмные снимки веба, iOS и Android перезаписаны. Префиксы токенов `ttr_`/`ttp_` (старые `kzr_` на стенде работают — сверяется только хеш). Полный `verify.sh` после переименования — зелёный. Старые тома Docker `kerez_*` (≈ 836 МБ) ещё не удалены.

**Второй обход и доработка.** «Уже знаешь? Пройти испытание» у закрытого места (до 10 заданий из пропущенных мест, ≤ 2 ошибок; сдал — уроки «пройдено испытанием», слова в FSRS как Good; не сдал — ничего не меняется; учителю и заданиям не засчитывается) — веб, iOS, Android, миграция `0013_jump`, `docs/02` §2. Тропа на телефоне: компактная шапка места и однострочные плашки задания и повторения, текущий узел — на первом экране, тропа открывается на текущем месте. Тексты: «Повторить N слов», «Ввести код класса», квест «Пройдите всем классом N уроков» (текст — с сервера). Учитель: закреплённый низ листов, сводка класса с «Ещё N», итог действий внутри листов, доска на 1280×720; с плитки «Я учитель» вход ведёт сразу к условиям (`/teacher/login?as=teacher`), без повторного «Учиться / Я учитель». Тосты при открытом модальном листе — внутри листа (раньше были под ним). Тропа и тексты перенесены в iOS и Android (снимки `trail-today`, `trail-second-place`), APK стенда пересобран. Веб на моках, `swift test`, Android-проверки — зелёные; `pnpm e2e` и полный `verify.sh` после этих правок не прогонялись (порты заняты стендом в сети, `.env` — на 192.168.1.232).

**Обход продукта «глазами» на стенде и правки по нему.** Исправлено: кабинет учителя падал на http-адресе в сети (`crypto.randomUUID` — только в защищённом контексте; заменён на `uuidv7()`, запрет в `eslint.config.mjs`); перезагрузка страницы разлогинивала на стенде в сети (refresh-cookie уходила с `Secure`: Next dev отдаёт в `nextUrl` всегда `localhost`; теперь — по заголовку `Host`, тест в `packages/session/test/server.test.ts`). Урок: ошибочное упражнение возвращается не больше одного раза (`retry: true` только после первой ошибки — решает сервер, клиенты следуют флагу), дуэли в уроке — с третьего пройденного урока (`LESSONS_BEFORE_DUELS`, `docs/02` §3), карточка «Новое слово» по центру; после второй ошибки на листе только верный ответ. Учитель: главная со сводкой по классам (сегодня, задание, кто не занимался, заявки), «Прогресс» по местам, дуэли по центру; в консоли выключен значок Next. Онбординг «Учусь сам» на компьютере — по центру экрана. Демо-сид: у №07 теперь 5 голосов (дуэли не в первых двух уроках) — живая база `teletau` обновится после `pnpm demo:reset`. Веб на моках — 214/214. `pnpm e2e` после этих правок не прогонялся (порты заняты стендом).

**Стенд для проверки владельцем на телефоне.** `.env` переключён на адрес в локальной сети `192.168.1.232` (`PUBLIC_WEB_URL`, `PUBLIC_CONSOLE_URL`, `NEXT_PUBLIC_API_URL`) и `AUTH_DEMO_CLASS_CODE=000000`; прежний файл — `.env.bak-localhost` (вернуть перед `pnpm e2e`/`verify.sh`). Запущены `pnpm dev` и раздача APK на `:8080`. Последняя полная самопроверка: всё зелёное, кроме двух e2e, упавших на новых текстах и знакомстве с пчелой; исправлено, повторный прогон e2e не завершён.

**Приоритет владельца: идеальный пользовательский путь и UI/UX фронта, а не безупречный бэкенд.** Сделано к этому моменту: самостоятельное обучение «Учусь сам» (ADR 0022) на вебе, iOS и Android; кабинет учителя (задания, карточка ученика, отчёт); кабинет министерства и словарь для Фонда в консоли (ADR 0023). В работе три агента-дизайнера: раскладка для компьютера и лендинг (как веб Duolingo: меню слева, путь в центре, правая колонка), путь ученика и ощущение урока (первый запуск, звуки, итог, микрокопирайтинг), путь учителя (первый класс по шагам, страница класса, доска). Сборка веба — под блокировкой `.web-build.lock` в корне.

**Кабинет министерства, словарь для Фонда, правка контракта** (ADR 0023, миграция `0011_staff_roles`). Роли сотрудника `ministry` и `fund` (в контракте — расширяемый `StaffRole`, поле `Me.staffRoles`: `Role` закрыт базовой версией M1). Консоль: «Республика» — сводка крупными числами, динамика по неделям, районы → школы с сортировкой; малые группы (< 5 учеников) скрыты на сервере, с дополнительным скрытием против вычитания из итога; «Словарь для Фонда» — принятые пары с голосами по группам, «Предварительно, до M4», CSV и JSON. Новый модуль API `ministry` без таблиц (org, progress, consensus, порт identity). Демо-мир: 12 школ в 7 районах, ≈180 учеников, 9 «Учусь сам», демо-сотрудники `ministry@` и `fund@demo.teletau.local`. Контракт: `discriminator` у `AttemptAnswer`, `HoneyBreakdown.multiplier` — число без `enum`.

**Готово сверх M2:** Telegram-бот (`apps/bot`, ADR 0020, модуль API `telegram`); повторение слов FSRS-6 (векторы `contracts/test-vectors/srs/`), «Мой словарь», цель дня, «Пары», «Послушать»; курс v3 — 6 юнитов, 280 упражнений, 39 дуэлей, 28 слов с записями произношения из Wikimedia Commons; Android (`android/dist/teletau-m2-debug.apk`, `docs/demo/M2-android.md`) и iOS (`docs/demo/M2-ios.md`, нужен рантайм симулятора или iPhone) — играбельные клиенты ученика. В работе: кабинет учителя (задания классу, карточка ученика, отчёт CSV, печать), локальная озвучка; паритет мобильных (озвучка, словарь, задания). Дальше: кабинет министерства в консоли (сводка по районам и школам), выгрузка подтверждённых пар для Фонда, правка контракта (`discriminator` у `AttemptAnswer`, `multiplier` числом), полная самопроверка с мобильными, жюри перед показом.

**Кабинет учителя и озвучка.** Задания классу (новый модуль `assignments`, ADR 0021, миграция `0009_assignments`): урок, «Испытание места» или «Повторить слова» со сроком, не больше двух активных; у ученика — карточка на тропе, заданный урок открыт; у учителя — вкладка «Задания» с выполнением по номерам мест. Карточка ученика по номеру места (`getSeatProgress`), «Скачать отчёт» (CSV) и печатная версия «Прогресса». В демо-мире — активное задание «Моя школа» до пятницы. Озвучка — со своего сайта: `scripts/prepare-audio.mjs` (при сборке веба) кладёт копии `content/audio` в `apps/web/public/audio` (AAC m4a + оригинал Ogg; m4a — встроенным `afconvert` macOS: ffmpeg из Homebrew не запускается), API в `audio`/`promptAudio` отдаёт `url: /audio/<id>.m4a` и `files` (m4a, ogg) — их играют iOS, Android и все браузеры; курс поднят до version 4; `upload.wikimedia.org` убран из CSP.

**Доработка продукта по всем каналам** (владелец: «вебу, веб апп, приложение — всё нужно дорабатывать»). Запущены параллельно: **iOS** (SwiftUI, играбельный клиент: вход по QR и коду, тропа, урок, итог, лига, профиль; клиент из контракта; снимки), **Android** (Compose, то же + debug-APK для телефона), **Telegram-бот** (long polling, кнопка Mini App, напоминания по согласию, привязка через проверку подписи `initData`, новый модуль API `telegram`). После `verify.sh` — углубление веба: повторение слов (FSRS), «Мой словарь», цель и задание дня, новые типы упражнений, уроки юнитов 3–6. От владельца понадобятся: токен бота (@BotFather), HTTPS-адрес для Mini App, при желании — рантайм iOS-симулятора или Apple ID для установки на iPhone.

Владелец отказался от кадров анимации пчелы (blink/wings); анимации на готовых картинках остаются. Получены и обработаны вывески и декорации мест 4–6, переделан `empty-no-students`. В работе: контент v2 (юнит 2 «Шүлгәнташ · Семья» полностью, закрытые юниты 4–6 Ямантау / деревня / Сабантуй), картинки мест 4–6 на тропе, единый знаменатель «Занимались N из M». Ласточка-аватар пока старая.

**M2 собрана: играбельный продукт готов к показу.** Части Ч0–Ч5 и «Сборка» закончены. Как показать: `pnpm demo:reset` (в день показа), затем `pnpm dev`; сценарий и данные для входа — `docs/demo/M2.md`. Проверено: весь сценарий §1 шаги 1–6 headless против настоящего API, снимки — `e2e/screens/m2-demo/`; `pnpm e2e --repeat-each=3` — 9/9; `verify.sh --skip-mobile` на Node 24 — зелёный (интеграционные 249/249). Не проверено: шаг 7 (Telegram) — нужен HTTPS-адрес и бот в @BotFather. **«Живой» веб:** подключены картинки второй партии (36 аватаров ников, сцены дуэли, «Принят», созревшего мёда, улья класса, пчёлы, заморозка, пейзаж стартовой страницы) и анимации по `design/prompts/batch-3-animation.md` (`docs/05` §9, новые токены `duration.*`, `easing.inOut/spring/fall`); заголовок «Помогите языку» больше не уходит под шапку. Места 4–6 (Ямантау, деревня, Сабантуй) подключены к тропе; «Занимались N из M» у учителя и ученика считается одинаково — по ученикам с аккаунтом (`ClassWeekSummary.studentsTotal`); из интерфейса убраны технические объяснения (правила подсчёта голосов, источники, «эксперт», возрастной режим, пояснения о приватности) — решение владельца.
