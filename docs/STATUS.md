**Почта и для детей (2026-11-10, решение владельца).** «Сохранить прогресс по почте» разрешено детям: в профиле
«Учусь сам» ссылка теперь у всех без привязанной почты, экран тот же (код из письма). Ключевое отличие: у ребёнка
сам адрес не хранится — в `credentials` только HMAC-хеш (ключ входа), строки `pii` нет (триггер 0002 не тронут),
в `Me` приходит флаг `emailLogin`, а не адрес (правка ADR 0009, оформлена в ADR 0022 §10). Вход ребёнка по почте —
сразу на тропу (раньше страница входа выкидывала любого не-взрослого с «Это вход сотрудника»). Контракт:
`POST /me/email` x-access `[adult]` → `[student, adult]`, новое поле `Me.emailLogin` — обратно совместимо.
152-ФЗ: до продакшена решить согласие родителя (привязку подтверждает сам ребёнок кодом из письма).
Тесты: API integration self-learners + authz-matrix — 172 зелёных (новый детский поток: флаг без адреса, вход по
почте — тот же аккаунт, карточка отозвана); веб self-learners + steps + errors + a11y + screens — зелёные
(новые: привязка ребёнком, вход ребёнка по почте на тропу); снимки перегенерированы (57-профиль, 60b-детская
привязка). Полный `pnpm e2e` не гонялся — порты заняты стендом.

**Чистка «нейрослопа» в текстах интерфейса (2026-11-10).** По замечанию владельца вычищены конструкции, по которым
генерированный текст легко опознаётся (аудит по открытым гайдам: отрицательный параллелизм «не просто X — это Y»,
рубленый тире-ритм в коротких строках, пустые утешители «останется с тобой», тройки, канцелярит, «Важно:»).
Исправлены: подсказки у ввода кода класса («Шесть букв и цифр — он на доске» → «Код написан на доске в классе»;
факты сохранены, тире-ритм убран; количество ячеек и так показывает CodeInput), «Мёд и серия останутся с тобой» →
«Мёд и серия сохранятся», «Тебе поможет карточка входа — она в профиле» → «…карточка входа из профиля»,
«Чтобы не потерять мёд и серию» → «Сохранит мёд и серию», ошибка ввода «В коде — только буквы и цифры с доски» →
«В коде — только буквы и цифры». Оставлены как информативные: «Заявка не потеряется» (офлайн-накопление — факт),
«Ответы не пропадут», «эта страница сама обновится» (опрос — факт), «Новичку аккаунт создастся сам»
(авто-регистрация — факт). Законные predicative-тире («Каждую неделю — новая лига», «за каждый — мёд») не тронуты.
Мобильные приложения и консоль — чисто. Тесты: errors/self-learners/steps/class-page/a11y/screens — 231 зелёный,
снимки с изменёнными текстами перегенерированы (04, 05, self/57, self/59, self/60).
