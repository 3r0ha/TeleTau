## План доработки (раунд 3)
1. **P1 — M1-35.** Одна проверка «можно ли войти на это место» в публичном сервисе org/consent: класс не в архиве, согласие не отозвано. Её вызывают:
   - QR-вход;
   - первая выдача сессии при опросе заявки;
   - повторная выдача при опросе.

   Перевыпуск карточки, отзыв согласия и архив класса в своей транзакции закрывают выдачу по заявкам аккаунта места (`expires_at = now()`). Тесты сначала, они должны падать на текущем коде:
   - одобрение → опрос → отзыв согласия → повторный опрос: сессии нет, 403 `consent_revoked`;
   - то же для перевыпуска;
   - отзыв согласия до первого опроса → 403 `consent_revoked`.
2. **P2:**
   - **M1-36:**
     - Резерв не отклоняет верные попытки, пока неудач меньше `max`. Счётчики «неудачи» и «в работе» ведутся в одном Lua-скрипте.
     - Если упираемся только в «в работе», сервер коротко ждёт и повторяет резерв; если ожидание не помогло — 429 с `Retry-After: 1`, а не остаток окна.
     - Лимит кода класса пересчитать под школу за одним NAT: неудачи — на устройство и с потолком на IP. Обоснование вероятности угадывания и роли одобрения учителя — в ADR 0016 §6.
     - Тесты: 30 параллельных верных QR с одного IP — все 200; класс из 30 за одним IP после 10 опечаток — все верные коды проходят; пачка неверных по-прежнему даёт ровно `max` неудач.
   - **M1-37:** выпуск первой карточки на место с аккаунтом тоже завершает сессии (`card_reissued`) и закрывает выдачу по заявкам. Текст диалога соответствует поведению. Тест.
   - **M1-38:** при ошибке проверки фокус переходит на первое неверное поле (`aria-invalid`, `aria-describedby`) во всех формах взрослого. Тест в `apps/web/test/e2e`.
3. **P3:**
   - **API:** M1-40 (общий запрет NUL и управляющих символов в строках запроса, 422; матрица тестов), M1-41.
   - **Клиенты:** M1-39 (токен процесса для отметки адреса в `packages/session`), M1-42…M1-46.
   - **Скрипты и документы:** M1-47, M1-27.
4. **Самопроверка:** `verify.sh` целиком на Node 24, e2e `--repeat-each=2`. Затем раунд 3 — все четыре жюри: у security P1, у остальных открытые находки и регресс.
