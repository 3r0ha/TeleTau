## План доработки (раунд 2)
1. **P1:**
   - **M1-01:** ошибки БД пишутся в лог без `params`, только SQLSTATE, операция и ограничение. Управляющие символы во вводе отклоняются ответом 422. Тест: принудительная ошибка БД при подаче заявки — ФИО в логе нет.
   - **M1-02:** QR содержит только полезную нагрузку `TT1.…`, без URL. На карточке печатается адрес сайта и шаги «Я ученик → Сканировать карточку». Маршрут `/q#…` убирается или больше не принимает секрет. ADR 0016 обновляется. В e2e проверяется, что в истории профиля нет `TT1.`.
   - **M1-03:** перевыпуск отзывает все сессии ученика места (`card_reissued`) и пишет об этом в аудит; в интерфейсе — предупреждение. Тест.
2. **P2 — API:**
   - **M1-04:** починить логгер; при сбое Valkey повтор refresh отвечает 503.
   - **M1-05:** атомарные лимиты через Lua «INCR и сравнение» для QR, карточки, кода класса и OTP; BFF не передаёт чужой `X-Forwarded-For`; ответ на код класса без школы.
   - **M1-06:** маркер «в работе» для `Idempotency-Key` и хеш тела.
   - **M1-07:** повторный опрос с тем же `X-Poll-Token` и устройством снова выдаёт сессию до истечения срока заявки.
   - **M1-08:** короткое льготное окно для повтора с того же устройства; дополнить ADR 0015.
   - **M1-09:** аудит один раз на семейство; лимит частоты на `/auth/refresh`.
   - **M1-17:** прочерк при импорте считается пустым значением.

   На каждое исправление — тест на параллельную пачку или на повтор.
3. **P2 — клиенты:**
   - **M1-10:** вынести код в `packages/ui` и `packages/session`.
   - **M1-11:** CSP с nonce, HSTS, `frame-ancestors`, `Permissions-Policy`.
   - **M1-12:** галочка и граница ≥ 3:1 у выбранного; шоколадное кольцо фокуса на мёде; новые пары в тесте контраста.
   - **M1-13:** выход на всех экранах-тупиках.
   - **M1-14:** шаг в URL, черновик в `sessionStorage`.
   - **M1-15:** заголовок у каждой страницы, фокус на `h1` при смене шага.
   - **M1-16:** API выставляет `uiMode` по классу; веб ставит `data-mode`, в режиме `bee` цели 56 px и крупнее текст; согласовать §3 и §7.
   - **M1-18:** таймеры считаются от времени ответа сервера.
4. **P3:** все открытые P3 из таблицы, кроме перенесённых.
