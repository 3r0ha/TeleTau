## План доработки (раунд 2)
1. **P1 M0-01 (+M0-12):** обработчики `error` у `pg.Pool` и ioredis (логи без ПДн, с троттлингом), обработчики у BullMQ worker/queue; интеграционный тест «`pg_terminate_backend` → процесс жив → следующий health 200»; шаг в демо.
2. **P2 M0-02, M0-03, M0-14, M0-15, M0-16** (bashkir-text, три платформы): повторный NFC в конце алгоритма; ZWJ удаляется только рядом с буквами; сборка строки частями; собственная таблица нижнего регистра (латиница, греческий, кириллица), одинаковая на всех платформах; табличный набор векторов, сгенерированный из `bashkir-homoglyphs.json`; дифференциальный набор «фазз-векторов» с ожиданиями от эталона; раннеры сканируют каталог; property-тесты идемпотентности и NFC.
3. **P2 M0-04, M0-05:** исправить определение «запущен как скрипт»; тест с пробелом и кириллицей в пути; схемы Drizzle по модулям, правила владения таблицами в проверке границ.
4. **P2 M0-06:** полный разбор `VALKEY_URL` (пользователь, пароль, БД, TLS) + тест `rediss://`.
5. **P2 M0-07:** убрать `additionalProperties: false` из ответов; проверка в `contracts:check`, запрещающая его в схемах ответов.
6. **P3 M0-08…M0-11, M0-13, M0-17, M0-18:** problem+json для ошибок фреймворка; расширенная проверка цветов; согласованное чтение `.env`; дев-раннер без двойного старта; iOS-сравнение с эталоном; документация; поиск секретов в `verify.sh` (если gitleaks установлен).
