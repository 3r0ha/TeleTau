# 00. Видение продукта

> Имя бренда — **«ТелеТау»** (теле — язык, тау — гора), подзаголовок — «Башкирская языковая школа». Имя, названия механик и все башкирские слова в этом пакете документов **требуют проверки носителем и Фондом башкирского языка** (см. `14-owner-tasks.md`). Альтернативные имена: «Умарта» (улей), «Һүҙлек» (словарь), «Тел юлы» (путь языка).

## 1. Одной фразой

**Каждый урок башкирского языка в ТелеТау — это одновременно шаг ученика и вклад в национальную базу переводов.** Дети, учителя и носители вместе учат язык и «собирают мёд»: подтверждённые сообществом и экспертами пары переводов, которые платформа отдаёт по открытому API школам, Фонду башкирского языка, разработчикам и исследователям.

## 2. Проблема

| Для кого | Боль |
|---|---|
| Школьник | Башкирский в школе — «ещё один предмет»: мало практики, нет игры, нет ощущения, что язык нужен «вживую». Привычные приложения (Duolingo и аналоги) башкирского не поддерживают. |
| Учитель башкирского | Нет современного инструмента для домашних заданий и мотивации; проверка — вручную; отчётность — вручную. |
| Носитель (в т.ч. ребёнок из сельской башкирской школы) | Его знание языка нигде не «засчитывается» и не превращается в общественную ценность. |
| Фонд башкирского языка, министерство | Нет живой, растущей, проверенной базы современных переводов и терминов; нет данных о том, кто и как учит язык; цифровые инструменты разрознены. |
| Разработчики, исследователи, ИИ | Мало качественных открытых параллельных данных рус↔баш — машинный перевод и языковые модели слабы на башкирском. |

## 3. Решение — два контура, одна механика

```
          ┌─────────────── КОНТУР ОБУЧЕНИЯ ───────────────┐
          │ уроки · повторение по FSRS · ежедневная миссия │
          │ стрики · лиги · рейтинги классов и школ         │
          └───────────────┬───────────────▲────────────────┘
                 задания на перевод   проверенные пары → упражнения,
                 и проверку вариантов  подсказки, AI-тьютор (RAG)
          ┌───────────────▼───────────────┴────────────────┐
          │ КОНТУР КОРПУСА (Consensus Engine)              │
          │ исходники → варианты → голоса/дуэли → эксперт  │
          │ → «запечатанная ячейка» → релиз датасета / API │
          └────────────────────────────────────────────────┘
```

Маховик: больше учеников → больше проверок → больше подтверждённых пар → лучше упражнения и AI-подсказки → интереснее учиться → больше учеников. Параллельно растёт ценность для Фонда и внешних потребителей API.

## 4. Позиционирование и уникальность

**«Не просто учим язык — вместе строим его цифровое будущее».**

Семь отличий от Duolingo и региональных приложений (подробное сравнение — `11-market-competitors.md`):

1. **Двойная ценность каждого действия.** Урок не только учит, но и создаёт общественное благо — открытый корпус. Ученик видит свой вклад: «твой вариант вошёл в словарь», «твою проверку использовали 1 240 раз».
2. **Коллективная игра, а не только индивидуальная.** Класс, школа и район играют командой: общий «улей», общий орнамент-тамга класса, «битва районов» на карте Башкортостана. Рейтинги честные: нормируются на размер класса и делятся на лиги по типу школы.
3. **Носители — герои.** Сельские школы с обучением на башкирском получают статус «хранителей мёда»: их проверки весят больше, а рейтинг это отражает. Социальный смысл: язык ценен, а значит ценен и тот, кто на нём говорит.
4. **Культурная укоренённость в каждом пикселе.** Метафора бортевого пчеловодства (борть, бурзянская пчела, липовый мёд), башкирский орнамент как система визуального языка, курс как экспедиция по Башкортостану, сезоны по национальным праздникам.
5. **Прозрачное качество.** Механика согласования вариантов взвешивает голоса по надёжности (Dawid–Skene, попарные дуэли по Bradley–Terry, контрольные задания), а у каждой подтверждённой пары есть «карточка происхождения» — почему она принята.
6. **AI, который не выдумывает башкирский.** GigaChat объясняет, подсказывает, генерирует исходники на русском и помогает модерации, но любой башкирский текст, который видит ученик, берётся из проверенной базы или явно помечен как «машинный, не проверен».
7. **Везде, где есть ученик.** Веб, нативные iOS и Android (офлайн-режим для сёл со слабой связью, виджеты, хаптика), Telegram-бот и Telegram Mini App, режим «урок-битва» для интерактивной доски в классе.

## 5. Принципы продукта

1. **Сначала ученик, потом корпус.** Задача на перевод показывается, только если она полезна для обучения на текущем уровне. Учебный опыт не жертвуется ради сбора данных (главный урок свёрнутого краудсорсинга переводов в Duolingo, см. исследование).
2. **Этичная геймификация для детей.** Никаких платных «восстановлений стрика», лутбоксов и рекламы. Заморозка стрика бесплатна, тихие часы для пушей, мягкие лимиты экранного времени, без стыжения за пропуски.
3. **Privacy by design.** Платформе не нужно настоящее имя ребёнка: вход по QR-карточке класса, псевдонимный ник. Данные хранятся в РФ.
4. **Носитель — главный эксперт, AI — помощник.** Решающее слово по языку всегда за людьми.
5. **Открытость.** Проверенная база публикуется версионированными релизами с открытой лицензией (решение за заказчиком), API документирован.
6. **Двуязычный интерфейс.** Интерфейс на русском и башкирском, с режимом «погружение».
7. **Уважение к вариативности.** У одного русского предложения может быть несколько правильных переводов (литературный, разговорный, диалектный) — система хранит множество принятых вариантов, а не «единственно верный».

## 6. Целевые аудитории

| Сегмент | Роль в системе | Ключевая ценность |
|---|---|---|
| Школьники 1–11 классов РБ (изучающие башкирский как родной и как государственный) | Ученик / ученик-носитель | Игра, прогресс, признание, команда класса |
| Учителя башкирского языка | Учитель | Готовые задания, автопроверка, аналитика, отчёты, «урок-битва» |
| Родители | Родитель | Прозрачный прогресс ребёнка, еженедельный дайджест |
| Эксперты-филологи (Фонд, вузы, методисты) | Эксперт | Очередь спорных переводов, терминологические заявки, качество корпуса |
| Фонд башкирского языка | Партнёр / потребитель API | Растущая проверенная база, заказ переводов терминов, аналитика |
| Министерство просвещения РБ | Аналитик / заказчик | Карта вовлечённости по районам и школам, отчётность, KPI госпрограммы |
| Взрослые изучающие, диаспора | Взрослый ученик | Самостоятельное изучение, связь с культурой |
| Разработчики, исследователи | Потребитель API | Открытые параллельные данные рус↔баш |

Продукт подходит и для самостоятельного изучения — без школы и учителя: путь «Учусь сам» для детей и взрослых без персональных данных (ник и возрастной диапазон), вход с другого устройства по личной карточке, класс — по желанию (ADR 0022).

## 7. Метрики успеха

**North Star Metric:** *еженедельно активные участники корпуса* (WAC) — ученики, которые за неделю прошли ≥3 учебные сессии **и** внесли ≥1 засчитанный вклад в корпус. Метрика связывает оба контура.

| Группа | Метрика | Цель через 12 мес. после запуска (базовый сценарий) |
|---|---|---|
| Охват | Подключённые школы / классы | 40% школ РБ с уроками башкирского; ≥1 активный класс в каждом районе |
| Вовлечённость | DAU/MAU | ≥ 30% |
| Удержание | D1 / D7 / D30 | 55% / 35% / 20% (учебный трафик через учителя выше рыночных бенчмарков) |
| Обучение | Прирост освоенных единиц FSRS на ученика в неделю | ≥ 25 |
| Корпус | Подтверждённые пары в месяц | ≥ 20 000 |
| Качество корпуса | Точность консенсуса при выборочном экспертном аудите | ≥ 95% |
| Нагрузка экспертов | Доля пар, потребовавших эксперта | ≤ 15% |
| Учителя | Классы, активные еженедельно / подключённые | ≥ 60% |
| API | Активные потребители / запросы в месяц | ≥ 10 организаций |
| Безопасность | Инциденты с ПДн | 0 |

Цифры — стартовые гипотезы; уточняются после пилота (см. `09-roadmap.md`, этап «Пилот»).

## 8. Что входит в релиз 1.0 (не MVP)

Полный перечень — `01-product.md`. Коротко:
- веб-платформа: ученик, учитель, родитель, публичный словарь;
- консоль: эксперт, модератор, Фонд, министерство, администратор;
- нативные приложения iOS (Swift/SwiftUI) и Android (Kotlin/Jetpack Compose) с офлайн-режимом, пушами, виджетами;
- Telegram-бот + Telegram Mini App (учёба полностью доступна и без них — см. `08-infra-security-compliance.md` §8);
- Consensus Engine с экспертной эскалацией и контрольными заданиями;
- AI-слой на GigaChat с оценками качества и защитными ограничениями;
- рейтинги классов, школ и районов, лиги, сезонные события, «урок-битва»;
- публичный API, портал партнёра, версионированные релизы датасета;
- защита данных детей (privacy by design), мониторинг, резервное копирование, нагрузочное тестирование, аудит доступности.
