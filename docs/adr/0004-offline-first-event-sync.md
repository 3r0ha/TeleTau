# ADR 0004. Offline-first: синхронизация журналом событий, сервер — источник истины для баллов

- Статус: принято (M0, реализация — M2, M6–M7)

## Контекст
В РБ регулярно отключают мобильный интернет, у сельских школ слабая связь (research/03 §4.4).

## Решение
Клиенты хранят офлайн-пакеты контента и журнал событий с клиентскими UUIDv7. `POST /sync/push` идемпотентен по идентификатору события, `GET /sync/pull` — по курсору. Баллы, серии и рейтинги пересчитывает сервер из событий; клиент показывает предварительный результат.

## Последствия
Нет конфликтов «последний победил» для прогресса; подделка клиента не даёт баллов. Нужны тесты на повтор и переупорядочивание событий.
