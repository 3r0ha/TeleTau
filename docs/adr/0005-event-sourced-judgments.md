# ADR 0005. Event sourcing голосов в Consensus Engine

- Статус: принято (M0, реализация — M4)

## Решение
Таблица `judgments` — только вставка. `item_state` всегда пересчитывается из журнала голосов, каждое решение хранит версию правил. При улучшении алгоритма вся база пересчитывается, а разница становится видна до применения.

## Последствия
Полный аудит решений, «карточка происхождения» пары, ежедневный экспорт журнала в неизменяемый архив.
