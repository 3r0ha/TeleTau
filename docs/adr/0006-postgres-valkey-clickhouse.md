# ADR 0006. PostgreSQL + Valkey + ClickHouse + S3

- Статус: принято (M0)

## Решение
- PostgreSQL 17 с pgvector и pg_trgm — основное хранилище, а также поиск по словарю (триграммы, векторы).
- Collation `ba_tailored` (`&Э < ә <<< Ә`) — башкирская сортировка: в CLDR её нет, а корневая сортировка ставит Ә после А. Миграция `0000_init`, проверена интеграционным тестом.
- Valkey — кеш, лидерборды (sorted sets), очереди BullMQ, pub/sub.
- ClickHouse — обезличенная аналитика и дашборды.
- S3-совместимое хранилище — медиа, офлайн-пакеты, релизы датасета. Локально — SeaweedFS 4.51: образы MinIO больше не публикуются на Docker Hub.

## Последствия
Локально всё поднимается `docker compose` на нестандартных портах хоста (15432, 16379, 18123, 18333), чтобы не конфликтовать с другими проектами разработчика.
