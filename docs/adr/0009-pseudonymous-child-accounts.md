# ADR 0009. Псевдонимные детские аккаунты (privacy by design)

- Статус: принято (M0, реализация — M1)

## Решение
Ребёнок входит по QR-карточке или коду класса с PIN и получает ник из генератора. ФИО, дата рождения, телефон, e-mail, фото, геолокация и национальность не собираются; связка «ник ↔ ученик» есть только у учителя (рукописная подпись на карточке). Персональные данные взрослых — в отдельной схеме `pii` (создана миграцией `0000_init`).

## Последствия
Утечка базы не раскрывает личности детей. Нет персональных данных в логах, аналитике, пушах, сообщениях бота и промптах.
