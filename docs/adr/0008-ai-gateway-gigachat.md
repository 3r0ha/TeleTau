# ADR 0008. AI-шлюз: GigaChat за абстракцией; «LLM не публикует непроверенный башкирский»

- Статус: принято (M0 — каркас; M5 — реализация)

## Решение
Все вызовы LLM идут только через `apps/ai-gateway`: интерфейс `LlmProvider`, мок-провайдер для разработки, GigaChat (Cloud.ru / API Сбера) с M5. Шлюз отвечает за бюджеты, кеш, реестр промптов, очистку ПДн и валидаторы вывода, в том числе валидатор закрытого словаря (`docs/04-ai-gigachat.md` §5.3).

## Последствия
Клиенты никогда не вызывают LLM напрямую. Без ключа продукт работает на моке.
