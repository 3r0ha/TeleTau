# ADR 0013. Никакого Python в репозитории

- Статус: принято (решение владельца)

## Решение
Весь серверный код, скрипты и пакетные ML-расчёты — на TypeScript. Dawid–Skene, Bradley–Terry и симулятор консенсуса реализуются в `apps/ml-worker`. Модели (эмбеддинги, восстановление диакритики, распознавание речи в R2) запускаются через ONNX Runtime для Node или готовые серверы инференса, без собственного Python-кода.

## Последствия
Один язык на сервере, один менеджер пакетов, одна CI-цепочка. Эталонные Python-библиотеки (например, crowd-kit) не используются: корректность алгоритмов проверяется тест-векторами на синтетических данных с известной истиной.
