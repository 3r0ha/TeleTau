# ADR 0001. Модульный монолит на TypeScript (NestJS + Fastify)

- Статус: принято (M0)

## Контекст
Небольшая команда и разработка с AI-агентами; четыре клиента и бот; нагрузка в пике — десятки тысяч одновременных пользователей в учебное время. Микросервисы на старте дали бы операционную сложность без выигрыша.

## Решение
Один деплой `apps/api` на NestJS 12 (ESM) с адаптером Fastify, разбитый на модули (`src/modules/*`) с публичным интерфейсом `index.ts`. Отдельными процессами живут только компоненты с иным профилем нагрузки: `ai-gateway`, `workers`, `ml-worker`, `bot`, веб-приложения. TypeScript — один язык для сервера, веба и бота.

## Последствия
- Границы модулей проверяются автоматически (`apps/api/scripts/boundaries.mjs`): импорт чужого модуля — только через `index.ts`, infra не зависит от модулей, нет циклов.
- Первые кандидаты на выделение в сервисы при росте: `realtime`, `consensus`.

## Альтернативы
Микросервисы (отклонено: стоимость эксплуатации); Kotlin/Spring (отклонено: второй язык на сервере, медленнее итерации); Go (отклонено: нет общих типов с вебом и ботом).
