# ADR 0011. Rive для анимации маскотов на всех платформах

- Статус: принято (M0, внедрение — M3, M6–M7)

## Решение
Одна анимация `.riv` с машиной состояний (`mood`, `talking`, `tap`) работает в вебе, на iOS и Android через официальные рантаймы Rive. Отдельный вариант без резких движений для режима «Уменьшение движения».

## Альтернативы
Lottie (нет полноценной машины состояний), нативные анимации на каждой платформе (тройная работа).
