# ADR 0003. Полностью нативные клиенты + общие тест-векторы

- Статус: принято (M0)

## Контекст
Требование владельца: нативные iOS и Android, не Flutter. При этом часть логики должна работать одинаково на сервере и офлайн на телефоне: нормализация башкирского текста, проверка ответов, FSRS, начисление баллов, орнамент.

## Решение
iOS — Swift 6/SwiftUI, Android — Kotlin/Jetpack Compose, без кроссплатформенных фреймворков (включая KMP). Общая логика реализуется на каждой платформе и проверяется **одними JSON-векторами** из `contracts/test-vectors/`. Таблицы данных (например, правила нормализации) генерируются для всех платформ из одного JSON (`pnpm codegen`), актуальность проверяется в CI.

## Последствия
- В M0 все наборы векторов `bashkir-text` проходят на TS, Swift и Kotlin; каждый порт объявляет поддерживаемые версии наборов и падает, если набор новее.
- Изменение поведения = новая версия набора векторов + обновление всех реализаций в одном изменении.

## Альтернативы
KMP для общей логики (−15–25% мобильных трудозатрат, `docs/12-finance.md`) — возможен по решению владельца, но по умолчанию не используется.
