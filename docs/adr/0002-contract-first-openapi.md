# ADR 0002. Contract-first: OpenAPI 3.1 — единственный источник правды

- Статус: принято (M0)

## Контекст
API потребляют веб, iOS, Android, Telegram-бот и внешние партнёры. Ручные DTO на каждой платформе расходятся.

## Решение
`packages/contracts/openapi.yaml` описывает API до реализации. TS-типы генерируются `openapi-typescript`, Swift-клиент — `swift-openapi-generator`, Kotlin — `openapi-generator`: оба подключаются вместе с сетевым слоем нативных приложений в M6 и M7 (уточнено на гейте M1, находка M1-27). До этого единственный потребитель — веб. `pnpm contracts:check`: линт Redocly (осознанные исключения — в `.redocly.lint-ignore.yaml` с обоснованием), актуальность сгенерированного, отсутствие ломающих изменений относительно `openapi.baseline.yaml` (oasdiff v1.35.0 в Docker).

## Последствия
Сервер импортирует типы ответов из `@teletau/contracts` (пример — `HealthController`). Базовая версия `openapi.baseline.yaml` обновляется **при закрытии каждой вехи**, это шаг закрытия в `/milestone`. Иначе ломающие изменения эндпоинтов прошлой вехи не будут пойманы (предложение жюри архитектуры, гейт M1).

## Альтернативы
Code-first (генерация спецификации из кода): отклонено — спецификация становится побочным продуктом, а клиентов у нас больше, чем серверов.
