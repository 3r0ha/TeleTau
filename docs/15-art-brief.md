# 15. Бриф на визуальные и звуковые ассеты (делает владелец)

Здесь всё, что нужно нарисовать, сгенерировать или записать вне кода: маскоты, иллюстрации, иконки, звуки, голоса. Для каждого ассета указаны назначение, требования и готовые промпты для нейросетей.

> **Важно про права.** Картинки из нейросетей подходят для **концептов и поиска стиля**. Финальные ассеты для госпродукта лучше перерисовать в векторе руками иллюстратора — тогда права на них чистые и их можно анимировать в Rive. Перед коммерческим использованием сгенерированного проверьте лицензию генератора: у Kandinsky/GigaChat, Шедеврума и Midjourney условия разные, у Midjourney коммерческое использование только на платном тарифе. Имя и маскота проверьте на совпадение с зарегистрированными товарными знаками (ФИПС).

### Как сделать серию согласованной
1. **Сначала пчела.** Когда поза `bee-idle` устроит, используй её как референс стиля (style/character reference) для всех остальных картинок.
2. Один и тот же префикс промпта для всей серии: техника, свет сверху слева, одинаковая обводка или её отсутствие.
3. Палитра — строго из §1. Без текста на картинках.
4. **Для векторизации:** плоские заливки без шума и сложных градиентов, до ~12 цветов, крупные формы — тогда векторный трассировщик даст чистый SVG.
5. Требования к SVG: без встроенного растра, с `viewBox`, ≤ 300 КБ. Если удобно — группы (крылья, глаза, рот, лапки отдельно): это понадобится для анимации в Rive.

## 2. Маскот №1 — «Бал», бурзянская пчела (рабочее имя)

**Почему пчела:** бурзянская бортевая пчела — живой символ Башкортостана (заповедник «Шульган-Таш»), а метафора «нектар → мёд → запечатанная ячейка» объясняет детям, как устроена проверка переводов.

| Параметр | Спецификация |
|---|---|
| Силуэт | Круглое тельце (почти шар), большая голова, крупные выразительные глаза, маленькие полупрозрачные крылья. Узнаваем в силуэте при 24 px |
| Окрас | Бурзянская пчела тёмная: тёмно-коричневое тело с узкими медовыми полосками (не жёлто-чёрная «мультяшная» пчела) |
| Национальный акцент (один, не перегружать) | Вышитый пояс с ромбическим орнаментом **или** маленькая тюбетейка с орнаментом **или** курай за спиной — выбрать после теста с детьми |
| Характер | Любопытный, добрый, немного неуклюжий трудяга; радуется чужим успехам больше, чем своим |
| Возраст/пол | Нейтральный |
| Обязательные эмоции | ожидание (idle), радость, ликование, задумчивость, сочувствие (после ошибки — не грусть, а «бывает, давай ещё»), удивление, сон, «объясняет» (указывает лапкой), машет |
| Поставка | Лист разворота (анфас, 3/4, профиль, спина) → лист эмоций → послойный SVG для Rive → файл `.riv` с машиной состояний |

**Машина состояний Rive (для разработчиков):** входы `mood` (число: 0 idle, 1 happy, 2 celebrate, 3 think, 4 sympathy, 5 surprise, 6 sleep), `talking` (bool — открывает рот во время озвучки), триггер `tap` (реакция на нажатие). Переходы плавные, длительность ≤ 400 мс, отдельный «тихий» вариант без резких движений для режима «Уменьшение движения».

| Музыка урок-битвы | 1–2 трека 60–90 с, лупы, с мотивами курая, лицензия на использование |

## 9. Голоса (озвучка носителями)

| Что | Объём к запуску | Требования |
|---|---|---|
| Ключевая лексика и фразы курса | ~2 000 единиц | Минимум 2 голоса (женский и мужской взрослый) + детский голос для фраз младшей школы (с согласия родителей и договором) |
| Истории юнитов | 12–20 историй по 1–2 мин | Выразительное чтение |
| Инструкции режима «Пчёлка» | ~50 фраз | Для детей, которые ещё плохо читают |
| Формат | WAV 48 кГц / 24 бит, тихое помещение, поп-фильтр, единый уровень громкости (−16 LUFS), имена файлов по ID из контента |
| Права | Договор с каждым диктором: лицензия на использование в продукте и в открытом голосовом корпусе (если планируется публикация) |

## 10. Шрифты

Рекомендация по исследованию (`research/02` §F4): текст — **Golos Text** или Onest, заголовки и детский режим — **Nunito** (все под OFL, полное покрытие башкирских букв). **Не использовать Manrope и Unbounded** — в них нет башкирских букв. Утвердить с дизайнером к M0. Если нужен уникальный акцидентный шрифт для бренда — заказ у шрифтового дизайнера с полным башкирским набором (опционально, R2).

## 11. Порядок работ по ассетам

1. Концепты маскота и иконки (нейросети) → тест с детьми на альфа-пилоте или в 2–3 классах (голосование «выбери маскота» — это ещё и вовлекающая акция) → выбор.
2. Согласование с Фондом и этнографом.
3. Иллюстратор: финальный вектор маскотов, лист эмоций, иконка → Rive-аниматор: `.riv` с машиной состояний (к M3 для веба, к M6–M7 для мобильных).
4. Иллюстрации юнитов (к M2 — первые 3, к M11 — все 12).
5. Звук и голоса (к M2 — пилотный объём, к M11 — полный).
