# Демо M2 — Android-приложение ученика

> **Сборка для телефона в той же сети:** `cd android && ./gradlew :app:assembleDebug -Pteletau.apiUrl=http://<IP компьютера>:4000` — тогда адрес сервера вшит по умолчанию и на телефоне ничего настраивать не нужно. Без свойства по умолчанию стоит адрес эмулятора `10.0.2.2:4000`, и на настоящем телефоне без настройки «Адрес сервера» будет «Нет сети».

Нативный клиент «ТелеТау» (Kotlin + Jetpack Compose) к тому же API, что веб. Сценарий показа — тот же, что в `docs/demo/M2.md` (шаги 1–4 и 6 — на телефоне вместо узкого окна браузера). Учитель по-прежнему работает в вебе на ноутбуке.

## Что готово

| Экран | Что видно |
|---|---|
| Заставка | Медовый экран с пчелой, пока восстанавливается вход |
| Старт | Пейзаж с брендом; «Я ученик» (с классом: карточка или код), «Учусь сам» (без класса, в любом возрасте), «Я учитель» (кабинет на сайте); «Войти: по карточке · по почте» (почта — на сайте); шестерёнка «Адрес сервера» |
| «Учусь сам» | Возраст (7–10, 11–14, 15–17, 18 и старше) → ник из словаря → «Начать» → сразу тропа. Цель дня не спрашиваем (по умолчанию 2 соты, меняется в профиле). Ничего личного |
| Вход по карточке | Камера (CameraX + ZXing), «Загрузить фото», «Ввести код класса». Один сканер для карточки места класса и личной карточки «Учусь сам» |
| Вход по коду класса | Код с доски → ник из словаря → «Ждём учителя» → «Ты в классе» |
| Первый вход по карточке | Выбор ника → «Ты в классе 5 «Б»» → «На тропу» |
| Знакомство | Первый заход на тропу (ещё ни одного урока): два листа с пчелой — «Привет! Я пчела» и «Урок — сота мёда» («Пропустить», «Начать урок», «Посмотреть тропу»). На этом телефоне — один раз |
| Тропа | Цель дня, серия, мёд, значок лиги; «Место N из 6»; «Задание учителя · до …» с «Начать задание» (выполненное — с галочкой); «Пора повторить N слов»; места с вывесками, декорациями и пчелой; липкий баннер места; «Впереди ещё N мест»; «На сегодня всё». Закрытый узел вздрагивает и подсказывает «Сначала пройди «…»». После урока тропа открывается на только что пройденном узле |
| Урок | «Переведи на башкирский» (плитки), «Что значит это слово?», «Напиши по-башкирски» с панелью букв ә ө ү ғ ҡ ң ҙ ҫ һ, «Соедини пары», дуэль «Помоги языку»; «Послушать» на карточке слова и в листе ответа (если у слова есть запись носителя). Задание въезжает справа; после «Проверить» ответ окрашивается (верный — зелёный с галочкой, выбранный неверный — коралловый с крестиком, «почти» — мёд); перед заданиями с новым словом — карточка «Новое слово» (слово, «Послушать», перевод, «Дальше»; ответа не ждёт); слова условия с переводом из словаря подчёркнуты пунктиром — нажатие показывает перевод; листы «Верно! / Почти! / Пока не так / Голос учтён» с одной кнопкой «Дальше»; с трёх верных подряд — огонёк «N подряд»; «Уже уходишь?». Короткие звуки (синтез, без файлов; молчат в беззвучном режиме и на вибрации) и отклик под пальцем |
| После урока | «Урок пройден!» (мёд, точность, время, новые слова, цель дня) → «N дней подряд» → «Новая лига — …!», везде «Дальше» |
| Вкладки | «Лига» (значки лиг, зоны повышения и понижения), «Класс» (квест недели, «Занимались N из M»), «Профиль» (аватар ника, итоги, «Мой словарь», «Моя карточка входа», «Мёд созрел!», «Мой вклад в словарь», настройки «Цель дня — Изменить», «Звуки», «Выйти») |
| «Моя карточка входа» | QR личной карточки, «Сохранить картинку» (в галерею, Pictures/TeleTau), «Сделать новую карточку». Без карточки выйти нельзя, не предупредив: «Сначала сделай карточку» |
| «Класс» без класса | «Класса пока нет» → «Вступить в класс» → код с доски → «Ждём учителя» → улей класса. Мёд и серия остаются. Взрослому — «Класс — для школьников» |
| «Мой словарь» | Из профиля: слова с переводами, «повторить» / «выучено», «Послушать», «Повторить» — если есть слова к повторению |
| Нет связи, ошибки | «Нет связи» с повтором, «Что-то сломалось», «Не получилось сохранить урок» |

Возрастной режим берётся из аккаунта: в «Пчёлке» (1–4 класс) цели нажатия 56 dp, шрифт крупнее, панель букв в два ряда; до входа — тоже «Пчёлка». Тема по умолчанию светлая (и в тёмной системе), тёмная — выключателем «Тёмная тема» в профиле; шрифт до 200 % поддержан. Системный «Назад»: с вкладки — на «Путь», в уроке — «Уже уходишь?», после урока — «Продолжить», с главного экрана — выход из приложения.

## Где APK

```
android/dist/teletau-m2-debug.apk       # адрес API по умолчанию — эмулятор, 10.0.2.2:4000
android/dist/teletau-m2-debug-lan.apk   # адрес API вшит: http://192.168.1.232:4000 (ноутбук показа в Wi-Fi)
```

Это debug-сборка: в ней разрешён HTTP без TLS — API показа работает по `http://<IP>:4000` в локальной сети. В release-сборке разрешён только HTTPS.

Пересобрать (из `android/`):

```sh
./gradlew :core:bashkirtext:test :app:assembleDebug
cp app/build/outputs/apk/debug/app-debug.apk dist/teletau-m2-debug.apk
```

## Поставить на телефон

Любой Android 8.0 и новее.

**По кабелю.** На телефоне включите «Для разработчиков» → «Отладка по USB». Затем на ноутбуке:

```sh
~/Library/Android/sdk/platform-tools/adb install -r android/dist/teletau-m2-debug.apk
```

Или из `android/`: `./gradlew :app:installDebug`.

**Без кабеля.** Перешлите `teletau-m2-debug.apk` на телефон (мессенджер, облако, флешка) и откройте файл. Телефон попросит разрешить установку из этого источника — разрешите. Повторная установка поверх старой сохраняет вход.

**Эмулятор Android Studio.** Перетащите APK в окно эмулятора. Адрес API менять не нужно: по умолчанию стоит `http://10.0.2.2:4000` — это ноутбук, на котором запущен эмулятор.

## Указать адрес API компьютера

1. На ноутбуке поднимите стенд, как в `docs/demo/M2.md`: `pnpm demo:reset`, затем `pnpm dev`. API слушает все сетевые интерфейсы (порт 4000).
2. Узнайте IP ноутбука в сети Wi‑Fi: `ipconfig getifaddr en0` (macOS). Пример — `192.168.1.10`.
3. Телефон — в той же сети Wi‑Fi. Гостевые и школьные сети с «изоляцией клиентов» не подойдут — раздайте Wi‑Fi с телефона учителя или используйте домашний роутер.
4. Если macOS спросит, разрешить ли `node` входящие подключения, — разрешите. Если файрвол включён без вопроса: «Системные настройки» → «Сеть» → «Файрвол» → «Параметры» → разрешить `node`.
5. В приложении на стартовом экране нажмите шестерёнку справа вверху → «Адрес сервера» → введите `http://192.168.1.10:4000` → «Проверить связь». Ответ «Связь есть — сервер отвечает.» → «Сохранить».

Ниже — «Адрес сайта». Пусто — тот же компьютер, порт 3000 (`http://192.168.1.10:3000`). С сайта играются записи «Послушать», если API отдаёт их относительным адресом (`/audio/…`); полный адрес записи играется как есть.

Адреса запоминаются на телефоне. Смена адреса API завершает вход на этом телефоне: сессия принадлежит серверу.

Кнопка «Я учитель или взрослый» открывает в браузере кабинет по адресу сайта: `http://<IP>:3000/teacher/login`. Чтобы веб открылся с телефона, в `.env` нужен `PUBLIC_WEB_URL=http://<IP>:3000` — см. `docs/demo/M2.md`, «Устройства».

## Сценарий на телефоне

Данные для входа — из `docs/demo/M2.md`, «Данные для входа».

1. **Вход по карточке.** «Я ученик» → «Сканировать карточку» → разрешите камеру → наведите на `.demo/student-card.png` на экране ноутбука. В отличие от браузера, камере приложения HTTPS не нужен. Без камеры — «Загрузить фото». Откроется тропа «Смелой пчелы».
2. **Урок «Моя школа»** — по таблице из `docs/demo/M2.md`, шаг 2. На шаге «тетрадь» наберите «дафтәр» с обычной «а»: появится «Почти!».
3. **После урока** — «Урок пройден!» → «6 дней подряд» → «Новая лига — Кипрей!» → тропа.
4. **Вкладки** «Лига», «Класс», «Профиль» → «Мой словарь».
5. **Задание учителя.** Учитель в вебе даёт классу задание (5 «Б» → «Задания»). На тропе телефона после обновления (вкладка «Путь») появится карточка «Задание учителя · до …» → «Начать задание».
6. **Шаг 6 — «Мёд созрел!».** После голоса учителя откройте «Профиль» ещё раз. Плашка появляется со второго захода в профиль на этом телефоне: первый заход запоминает, что уже видено.

**«Учусь сам».** Старт → «Учусь сам» → возраст → ник → «Начать» → знакомство с пчелой → тропа. Профиль → «Моя карточка входа» → «Сделать карточку» → «Сохранить картинку». На другом телефоне: «Я ученик» → «Сканировать карточку» → наведите камеру на картинку — тот же аккаунт со всем мёдом. Вкладка «Класс» → «Вступить в класс» → код **000-000** → учитель принимает заявку в вебе.

**Новый ученик без карточки:** «Я ученик» → «Ввести код класса» → код **000-000** → ник → «Отправить заявку». Учитель принимает заявку в вебе, и телефон сам переходит к «Ты в классе».

## Если что-то не так

| Что видно | Что сделать |
|---|---|
| «Нет связи» на заставке или тропе | Проверьте адрес («Проверить связь»), Wi‑Fi и файрвол ноутбука. На заставке есть «Попробовать снова» и «Войти заново» |
| «Эту карточку не удалось найти» | После `pnpm demo:reset` карточка новая — сканируйте свежую `.demo/student-card.png` |
| Вход сбросился сам | Сервер завершил сессию (перевыпуск карточки или новый `demo:reset`). Приложение объясняет это на стартовом экране; войдите снова |
| Камера не включается | Разрешите камеру в настройках приложения или войдите по фото карточки |

## Как устроено (коротко)

- **Клиент API генерируется** из `packages/contracts/openapi.yaml` при каждой сборке: openapi-generator 7.27, генератор `kotlin`, kotlinx.serialization + Ktor (модуль `android/core/network`, код — в `build/generated/openapi`). Ручных DTO нет.
- **Сессия** (`android/core/session`): access-токен — в памяти, refresh-токен — AES-GCM ключом Android Keystore; обновление строго одно на все запросы (single-flight); без сети вход не теряется.
- **QR-карточка и код класса** разбираются портом `@teletau/auth-codes` (`android/core/authcodes`), который проходит общие векторы `contracts/test-vectors/qr-card` и `class-code`.
- **Башкирский текст** приходит только из API и рисуется шрифтом Nunito с локалью `ba`: включаются башкирские формы Ҫ и Ҙ. Это проверяет тест `BashkirGlyphsTest`.
- Сторонних SDK аналитики и пушей нет. QR распознаёт открытая библиотека ZXing, без ML Kit.

Команды и модули — в `android/README.md`.
