# Демо вехи M0 — Фундамент

Цель демо — убедиться, что фундамент работает: одна команда поднимает всё, общая логика одинаково ведёт себя на трёх платформах, токены применяются везде, контракт и границы модулей защищены автоматикой.

Предусловия: Node 24+ (локально проверено на 25.9), pnpm 9, запущенный Docker Desktop; для мобильных — Xcode 26 с XcodeGen и Android SDK.

## 1. Одна команда — всё окружение (критерий 1)

```bash
pnpm install
pnpm dev
```

Ожидаемо:
- `docker compose` поднимает `postgres`, `valkey`, `clickhouse`, `s3` (SeaweedFS) — все `healthy`;
- применяется миграция `0000_init`;
- в логе: `workers: ping → {"pong":true,…}` (очередь BullMQ через Valkey работает), `bot: TELEGRAM_BOT_TOKEN не задан — бот работает вхолостую`.

Проверка в другом терминале:

```bash
curl -s localhost:4000/api/v1/health   # {"status":"ok","service":"api",…,"checks":{"postgres":"ok","valkey":"ok"}}
curl -s localhost:4100/health          # {"status":"ok","service":"ai-gateway",…,"provider":"mock"}
curl -s localhost:4200/health          # {"status":"ok","service":"ml-worker",…}
curl -s localhost:4000/api/v1/nope     # RFC 9457: {"type":"about:blank","status":404,…}
open http://localhost:3000             # стартовая страница на токенах, башкирские буквы фирменным шрифтом
open http://localhost:3100             # консоль
```

Отказоустойчивость health:
- `docker compose stop valkey` → `curl -i localhost:4000/api/v1/health` возвращает **503** с `"valkey":"down"`; `docker compose start valkey` → снова 200.
- `docker compose restart postgres` (рестарт присылает клиентам FATAL 57P01 и закрывает соединения) → API **не падает**: в логе одно предупреждение `postgres: 57P01: terminating connection…`, следующий `curl` — 200. Автотест: `apps/api/test/integration/resilience.test.ts` (обрыв соединений через `pg_terminate_backend`).
- «Тихий» сетевой разрыв без RST (failover с переездом узла, падение ВМ) — другой режим отказа: соединения не закрываются, а замолкают. Его проверяет тот же автотест через TCP-прокси «чёрная дыра» для Postgres и Valkey: во время разрыва health отвечает 503, после восстановления сети — 200 не дольше чем за 5 с (политика таймаутов — `docs/06-architecture.md` §6.8).
- Если порт одного из приложений занят другим процессом, `pnpm dev` сообщит об этом до старта и запустит остальные приложения.

## 2. Полная самопроверка (критерии 2, 6)

```bash
bash scripts/verify.sh
```

Ожидаемо: все шаги `✔` — зависимости, кодогенерация актуальна, линт + границы модулей + запрет хардкода цветов, типы, тесты TS, контракт, сборка, Docker, миграции, интеграционные тесты, iOS (`swift test` + сборка), Android.

## 3. Одни векторы — три платформы (критерий 3)

```bash
pnpm vectors                                                   # TS: все наборы каталога + версии наборов + свойства
swift test --package-path ios/Packages/TeleTauCore               # Swift: те же наборы + рендер экрана
cd android && ./gradlew :core:bashkirtext:test                 # Kotlin: те же наборы
```

Попробуйте сломать: поменяйте одну запись в `contracts/shared/bashkir-homoglyphs.json`, например замените `h → һ` на `h → х`, и запустите `pnpm codegen:check` — проверка назовёт 4 устаревших файла: таблицы TS, Swift и Kotlin и табличный набор `normalize-table.json`. После `pnpm codegen` на всех трёх платформах упадут одни и те же векторы: ручные `n026`, `n039`, `n049` и фазз-векторы `fuzz-normalize` и `fuzz-comparable` (по 46 в каждом при мутации `h → х`; ожидания фазз-наборов зафиксированы до мутации). Табличные векторы не упадут — `codegen` перегенерирует их вместе с таблицами. Наборы — ручные, табличные (из правил) и фазз — перечислены в `contracts/test-vectors/README.md`.

## 4. Токены — одинаково в вебе, iOS и Android (критерии 4, 5, 6)

- Веб: `http://localhost:3000` — светлая тема по умолчанию (и в тёмной системе), тёмная — выключателем «Тёмная тема» в профиле.
- iOS: `ios/Packages/TeleTauCore/Tests/DesignSystemTests/__Snapshots__/start-light.png` и `start-dark.png`. Тест сверяет цвет фона с токеном темы.
- Android: `cd android && ./gradlew :core:designsystem:verifyRoborazziDebug` — снапшоты стартового экрана (светлая, тёмная, шрифт 200%) в `android/core/designsystem/src/test/snapshots/`; `./gradlew :app:assembleDebug` → APK.
- Контраст WCAG 2.2 AA для всех пар текст/фон в обеих темах: `pnpm tokens:check` (все пары из `packages/design-tokens/tokens/contrast-pairs.json` в обеих темах).
- Попробуйте вписать `color: #ff0000` в `apps/web/app/globals.css` — `pnpm lint` упадёт с указанием файла и строки.

## 5. Контракт и границы модулей

- `pnpm contracts:check` — линт Redocly, актуальность TS-типов, oasdiff против `openapi.baseline.yaml`. Удалите поле `version` из схемы `Health` — проверка найдёт ломающее изменение.
- Добавьте в `apps/api/src/modules/health/health.service.ts` импорт из `../other/some.js` при существующем `src/modules/other/some.ts` — `pnpm --filter @teletau/api lint` сообщит о нарушении границы модуля.

## 6. Башкирская сортировка в базе

```bash
docker compose exec postgres psql -U teletau -c \
  "SELECT x FROM unnest(array['ю','ә','а','э','б']) x ORDER BY x COLLATE ba_tailored"
# а, б, э, ә, ю  — Ә после Э, как в башкирском алфавите
```
