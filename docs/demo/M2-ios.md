# Демо M2 на iPhone — приложение iOS

Как поставить приложение «ТелеТау» на свой iPhone через Xcode с бесплатной подписью Apple ID и подключить его к серверу
на ноутбуке. Сценарий показа и данные для входа — те же, что в `docs/demo/M2.md`: ученик проходит его в приложении,
учитель — в браузере на ноутбуке. Кабинет учителя есть только на сайте: кнопка «Я учитель или взрослый» открывает его.

## Что нужно

- Mac с Xcode 26.5 и XcodeGen (`brew install xcodegen`).
- iPhone с iOS 17 или новее и кабель.
- Apple ID. Платный аккаунт разработчика не нужен.
- Ноутбук и iPhone в одной сети Wi-Fi. Сеть не должна изолировать клиентов: в гостевых и школьных сетях телефон
  часто не видит ноутбук. Надёжнее всего раздать Wi-Fi с телефона или с ноутбука.

## 1. Сервер на ноутбуке

```sh
pnpm demo:reset   # в день показа: база с нуля и демо-мир, QR-карточка ученика — в .demo/student-card.png
pnpm dev
```

API слушает все адреса ноутбука на порту 4000. Узнайте адрес ноутбука в сети:

```sh
ipconfig getifaddr en0   # например, 192.168.1.5
```

Проверьте с телефона: откройте в Safari `http://192.168.1.5:4000/api/v1/health`, должен прийти ответ `{"status":"ok",…}`.
Если macOS спросит, разрешить ли `node` входящие подключения, — разрешите.

## 2. Проект в Xcode

```sh
cd ios
xcodegen generate
open TeleTau.xcodeproj
```

При первом открытии Xcode скачает пакеты Swift (рантайм swift-openapi-generator) — нужен интернет.

1. **Xcode → Settings → Accounts → «+» → Apple ID**: войдите своим Apple ID. Появится команда «… (Personal Team)».
2. Выберите проект **TeleTau** → таргет **TeleTau** → вкладка **Signing & Capabilities**:
   - **Team** — ваша «Personal Team»;
   - **Bundle Identifier** — замените `ru.teletau.app` на свой уникальный, например `ru.teletau.app.ivanov`.
     Бесплатная подпись не даст зарегистрировать идентификатор, который уже занят.
3. Можно сразу вписать адрес сервера в сборку, чтобы не вводить его на телефоне: таргет **TeleTau → Build Settings**,
   найдите **TELETAU_API_BASE_URL** и укажите `http://192.168.1.5:4000`. Иначе адрес вводится в приложении (шаг 4).
   После `xcodegen generate` настройки возвращаются к значениям из `ios/project.yml`. Чтобы адрес и команда
   сохранялись, впишите их там: `TELETAU_API_BASE_URL` и `DEVELOPMENT_TEAM` в `targets.TeleTau.settings.base`.

## 3. Установка на iPhone

1. Подключите iPhone кабелем, разблокируйте и нажмите «Доверять этому компьютеру».
2. Включите режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить,
   перезагрузить, подтвердить. Пункт появляется после первого подключения к Xcode.
3. В Xcode выберите свой iPhone в списке устройств вверху окна и нажмите **Run** (⌘R). В первый раз Xcode подготовит
   устройство (может занять несколько минут).
4. Если iPhone пишет «Ненадёжный разработчик»: **Настройки → Основные → VPN и управление устройством** → ваш Apple ID →
   **Доверять**. Затем снова нажмите Run.

Ограничения бесплатной подписи: приложение работает 7 дней, потом его нужно снова запустить из Xcode. На одном
устройстве — не больше трёх таких приложений.

## 4. Адрес сервера в приложении

1. На стартовом экране нажмите шестерёнку справа вверху → **Адрес сервера**.
2. Введите `192.168.1.5:4000` (`http://` можно не писать). Поле «Адрес сайта» можно оставить пустым: тогда это тот же
   адрес на порту 3000 (с него приложение берёт записи произношения и открывает кабинет учителя). → **Сохранить**.
3. При первом запросе iOS спросит доступ к локальной сети — **Разрешить**. Без него приложение покажет «Нет связи».

Адрес хранится на телефоне. Смена адреса закрывает вход ученика: на другом сервере другая сессия.

## 5. Показ

- **Ученик по карточке:** «Я ученик» → «Сканировать карточку» → разрешите камеру → наведите на `.demo/student-card.png`
  на экране ноутбука. Можно и «Загрузить фото» — снимок из галереи. Дальше — сразу тропа «Смелой пчелы».
  Шаги 1–4 и 6 сценария `docs/demo/M2.md` проходятся в приложении: урок «Моя школа» (карточки «Новое слово» перед
  упражнениями с новым словом, подсказки к словам условия — пунктир, нажатие показывает перевод, плитки, выбор, «Почти!» с «дафтәр»,
  дуэль), итог, серия, «Новая лига — Кипрей!», вкладки «Лига», «Класс», «Профиль». После «Проверить» ответ окрашивается
  (верно — зелёный с галочкой, не так — коралловый с крестиком), с трёх верных подряд на листе — огонёк «3 подряд»;
  после урока тропа открывается на только что запечатанной соте. Нажмите закрытый узел — он качнётся и подскажет
  «Сначала пройди «…»». Звуки урока синтезируются в приложении (без файлов), молчат в беззвучном режиме и выключаются
  в профиле («Звуки»). В профиле — «Мой словарь» с кнопкой «Повторить». Кнопка «Послушать» появляется только у
  записей в формате, который играет iPhone (не Ogg).
- **Первый вход:** у ученика без пройденных уроков поверх тропы — знакомство с пчелой (два листа, «Пропустить»);
  показывается один раз на устройстве.
- **«Учусь сам»:** на старте «Учусь сам» → возраст → ник → «Начать» → сразу тропа. Цель дня — 2 урока, меняется в профиле.
  В профиле — «Моя карточка входа»:
  на втором устройстве «Я ученик» → «Сканировать карточку» → наведите камеру на этот QR — откроется тот же аккаунт.
  «Сохранить картинку» кладёт карточку в Фото. Без класса во вкладке «Класс» — «Вступить в класс» по коду **000-000**.
- **Новый ученик без карточки:** «Я ученик» → «Ввести код класса» → код **000-000** → ник → «Отправить заявку».
  Учитель на ноутбуке принимает заявку — приложение само переходит на «Ты в классе».
- **Учитель:** «Я учитель» открывает сайт `http://<адрес ноутбука>:3000/teacher/login` в Safari.
  Чтобы сайт открылся с телефона, в `.env` задайте `PUBLIC_WEB_URL=http://192.168.1.5:3000` и
  `NEXT_PUBLIC_API_URL=http://192.168.1.5:4000` и перезапустите `pnpm dev` (`docs/demo/M2.md`, «Устройства»).

## Если что-то не так

| Что видно | Что сделать |
|---|---|
| «Нет связи» | Проверьте адрес (шестерёнка), что телефон и ноутбук в одной сети, `…/api/v1/health` в Safari, доступ к локальной сети: **Настройки → Конфиденциальность и безопасность → Локальная сеть → ТелеТау** |
| «Failed to register bundle identifier» в Xcode | Смените Bundle Identifier на свой уникальный (шаг 2) |
| «Ненадёжный разработчик» на iPhone | Доверьте свой Apple ID (раздел 3, шаг 4) |
| «Вход на этом устройстве завершён» | Сервер сбросили (`pnpm demo:reset`) или карточку перевыпустили — войдите по новой карточке |
| Камера не включается | **Настройки → ТелеТау → Камера** — включить, или «Загрузить фото карточки» |
| Приложение перестало открываться через неделю | Срок бесплатной подписи — 7 дней: запустите заново из Xcode |
