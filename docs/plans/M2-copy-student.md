# M2 — тексты ученика: «было → стало»

Редактура ученической части по просьбе владельца: «минимум нейрослоп конструкций в тексте, как и в целом текста:
интерфейс должен быть максимально интуитивным, простым, понятным и удобным». Источник истины — веб
(`apps/web/app/**` кроме `teacher/**`, `packages/session/src/problem.ts` — `CHILD`, `apps/bot`). iOS и Android
повторяют тексты и упрощения по этой таблице.

Объём видимого текста на экранах ученика: **≈ 14 000 → ≈ 9 600 символов (−32 %)**; на основных экранах −35…55 %
(старт −50 %, «Учусь сам» −55 %, ожидание учителя −46 %, профиль −38 %, словарь −39 %, знакомство с пчелой −40 %).
Подписи для читалки (`aria-label`, скрытые подписи) не сокращались.

## Правила, по которым правили

1. Подзаголовок — только если без него непонятно. Подсказка «нажми, чтобы…» — только если действие неочевидно.
2. Число и значок вместо фразы. Одно главное действие на экране.
3. Кнопка — короткий глагол: «Начать», «Проверить», «Дальше», «Повторить», «Выйти».
4. Нельзя: «— и …» для красоты, «Так держать!», «Ура», «путешествие», риторические вопросы, два «!» на экране,
   сюсюканье («Пчела скучает»), технические объяснения.
5. Новый башкирский текст не добавлялся. Из листа «Новая лига» убрана фраза про Аҡбуҙат (слово осталось только в
   подписи картинки для читалки).
