## Экраны и примитивы — готово

Готово по прототипу (`prototypes/trail-expedition/shots/`):
- заставка;
- тропа: карточка экспедиции, липкий баннер юнита, места с вывесками, декорациями и тропинкой, пчела, пузырь «Начать» с запасом над подписью, «штамп» пройденного узла;
- урок:
  - плитки;
  - выбор (1–4, Enter);
  - ввод с панелью букв (буквы из `FreeInputExercise.letters`);
  - дуэль (1–4);
  - листы «Верно / с опечаткой / Почти / Пока не так / Голос учтён»;
  - «Уже уходишь?» по крестику и по «Назад»;
- итог, серия (токены `streak.*`), «Новая лига»;
- вкладки «Лига», «Класс» (квест, участие, по дням), «Профиль»;
- пустые состояния: «Нет связи», «Что-то сломалось», «На сегодня всё» (полный экран), «Все пары уже оценены» (дуэли закончились).

Примитивы `packages/ui`:
- `HexNode`, `WordTile`, `AnswerOptions`, `LetterPanel`, `FeedbackSheet`, `HoneyComb`, `StatTile(s)`, `LeagueBoard`/`LeagueRow`/`LeagueZone`, `StudentTabBar`;
- иллюстрации — `illustrations.ts`.

`Duel` (`app/_components/learn/Duel.tsx`) принимает `sourceRu`, `a`, `b`. Учителю (Ч5) — `variants[0].text` и `variants[1].text` из `CorpusDuel`.

## Отличия от прототипа (осознанные)

- Нет счётчика дневной цели и кнопок озвучки — отложено в M2b, по плану.
- Текущая вкладка и выбранный вариант — с тёмной границей `accent.text` (контраст, M1-12).
- «Место 1 из 3» вместо «1 из 12»: в `Course` нет числа мест.
- Карточек «Индекс улья», «Классы школы», «Задание учителя» нет — это M9.
