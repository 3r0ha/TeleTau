# План вехи M2 — Играбельный продукт (M2 + M3, режим «сначала продукт»)

**Решение владельца.** M2 «Ядро обучения» и M3 «Мотивация» объединены в веху **M2 «Играбельный продукт»**:
- **к показу** — играбельный веб целиком по утверждённому прототипу и каркас Telegram Mini App на том же вебе;
- **жюри-агенты** до показа не запускаются, вместо гейта — облегчённая самопроверка (§5);
- **нативные iOS и Android** — после показа, шлифовка — в `docs/backlog.md` на M11.

**Опоры:**
- прототип — `prototypes/trail-expedition/` (`index.html`, `shots/`), решения по нему — `docs/05` §0;
- методика — `docs/02` §3–6;
- дуэль и группы голосов — `docs/03` §4a;
- данные — `docs/07` §1.2–1.4;
- модули — `docs/06` §3;
- Mini App — `docs/09` M8.

## 1. Цель и сценарий показа

**Цель.** Ученик по-настоящему играет: проходит урок на тропе, голосует в дуэли, видит мёд, серию и лигу. Учитель видит прогресс класса и сам голосует в дуэли. Всё работает на настоящем API и с контентом из открытых источников.

**Заглушек нет.** Отложенное на экранах не показывается вовсе — без плашек «скоро».

**Подготовка:** `pnpm dev`, затем `pnpm --filter @teletau/api demo:seed`. Сид печатает ссылку входа демо-ученика и e-mail демо-учителя (код 0000) и создаёт демо-мир:
- класс 5 «Б» на 24 места;
- демо-ученик «Смелая пчела»: серия 5 дней, пройдены 3 узла юнита 1;
- одноклассники с историей;
- лиговая группа с непросмотренным итогом прошлой недели;
- голоса детей и взрослых из других демо-школ.

**Сценарий (≈ 5 мин):**

| # | Кто | Что видит комиссия |
|---|---|---|
| 1 (0:30) | Ученик, телефон или узкое окно | **Заставка → тропа:** карточка экспедиции «Өфө · Знакомство»; медовые пройденные соты; текущий узел с пузырём «Начать»; фиолетовый узел «Помоги языку»; счётчики серии, мёда и лиги. **При прокрутке:** липкий баннер юнита, закрытые Шульган-Таш и Агидель с вывесками и декорациями |
| 2 (1:30) | Ученик | **Урок из 6–8 упражнений:** плитки (верно) → выбор (ошибка, «вернём в конце») → ввод с панелью букв (без особой буквы — «Почти! Обрати внимание на букву …») → дуэль → «Голос учтён» → повтор ошибочного упражнения |
| 3 (0:30) | Ученик | «Урок пройден!» (мёд, точность, время, новые слова) → «6 дней подряд», «2 заморозки в запасе» → «Новая лига — Кипрей!» → на тропе узел запечатан |
| 4 (0:40) | Ученик | **Вкладки.** «Лига»: зоны и ники. «Класс»: квест недели в сотах, «занимались 18 из 24». «Профиль»: серия, мёд, слова, голоса, «Мой вклад в словарь» |
| 5 (1:00) | Учитель, ноутбук | Вход по 0000 → класс 5 «Б» → **«Прогресс»:** «№07 · Смелая пчела — 3 урока, сегодня, серия 6», сводка недели. **«Помогите языку»:** та же дуэль; голос → голоса раздельно (дети / взрослые / учителя), статус «Принят» |
| 6 (0:20) | Ученик | Профиль: вариант «созрел», мёд за голос из «ждёт» стал начисленным |
| 7 (0:30) | Ученик в Telegram | Кнопка меню бота открывает ту же тропу: тема Telegram, системная «Назад», вход по QR сканером Telegram |

## 2. Объём

### Входит

**Веб ученика — экраны прототипа:**
- заставка;
- тропа;
- урок с листами «верно / почти / не так / голос учтён» и диалогом «Уже уходишь?»;
- после урока: итог, серия, повышение в лиге;
- вкладки «Лига», «Класс», «Профиль»;
- пустые состояния;
- кнопки озвучки нет.

**Упражнения:**
- `tiles_ru_ba`;
- `choice_ba_ru` — новый код: узнавание при первом знакомстве, дописать в `docs/02` §3;
- `free_ru_ba` с панелью букв;
- `duel`.

Проверка ответа — на сервере пакетом `bashkir-text`: `correct`, `almost` с буквой, `typo`, `wrong`.

**Курс:**
- юнит 1 «Өфө · Знакомство» — 4 урока, «Испытание места» и 2 узла «Помоги языку» по 3 дуэли;
- юниты 2–3 закрыты, но видны с вывесками;
- узла «фраза дня» нет.

**Мотивация:**
- мёд за урок с лимитом на повтор;
- «мёд созревает» за голос;
- серия по суткам Уфы с заморозками;
- недельная лига медоносов (5 тиров, группы ≤ 20 одной возрастной группы);
- квест класса на неделю.

Числа — в векторах (Ч0).

**Дуэль с голосами по группам** `child` / `teacher` / `adult`:
- правила v0 — до M4, ADR 0019;
- варианты — только из человеческих источников (`origin = import`).

**Учитель:**
- вкладка «Прогресс» класса;
- раздел «Помогите языку».

**Каркас Mini App** — экраны ученика под `/miniapp/*`. Из Telegram ничего не сохраняем.

**Демо-контент** из открытых источников с указанием источника.

**Демо-сид и сквозной тест** главного пути.

## 3. Части для параллельных агентов

**Правила для всех частей:**
- правила `CLAUDE.md` 1, 2, 4–9, 15;
- системное ПО не ставить: никаких `brew`, глобальных Node и JDK;

**Граф модулей API.** Он без циклов, это проверяет `boundaries.mjs`. Вызовы — через публичные сервисы в транзакции вызывающего, как `AuditService`. Outbox — в M4.

```
learning → content, corpus, consensus, progress      consensus → corpus, progress
progress → competition, org      competition → org, identity      content, corpus → (нет)
```

**Зависимости частей:**

```

                      ├─> Ч3 API дуэли ──────────────┤
```

| Операция | Доступ | Модуль | Смысл |
|---|---|---|---|

| `GET /leagues/current` · `POST /leagues/result-seen` | student, adult | competition | Тир, группа, зоны, конец недели по Уфе; итог прошлой недели |

| `GET /corpus/items/{id}/votes` | adult | consensus | Голоса по группам и статус — после своего голоса |
| `GET /corpus/my-cells` | student, adult; self | consensus | Мой вклад: созрело / ждёт |

**Векторы** (правило 2: ожидания выводятся из правил, а не из кода). Раннеры Swift и Kotlin читают только `bashkir-text/`, поэтому новые наборы их не ломают; порты — в M6/M7.

`answer-check/match.json` — `matchAnswer`:
- верно;
- регистр и пунктуация;
- двойники латиницы;
- «почти» на всех 9 парах букв (к/ҡ, г/ғ, з/ҙ, с/ҫ, х/һ, а/ә, о/ө, у/ү, н/ң) с позицией;
- опечатка;
- неверно;
- порядок плиток.

Строки — синтетические, не учебный контент.

`xp/`:
- урок — 10 + 1 за каждое упражнение с первой попытки (`almost` и `typo` засчитываются);
- повтор урока в те же сутки — половина, с третьего раза — 0;
- голос — `pending` 3, после решения `final`: 3 при согласии с итогом, 1 при несогласии;
- «Не знаю» — 0.

`streak/`:
- сутки по Уфе;
- цель дня — 1 урок;
- пропуск списывает заморозку, без заморозки серия обнуляется;
- старт с 2 заморозками, +1 за 7 дней подряд, максимум 2.

`consensus/duel-v0.json`:
- веса голосов: ребёнок 1, взрослый 2, учитель 3;
- эксперт решает окончательно;
- без голосов учителей и взрослых — `voting`;
- большинства учителей и взрослых расходятся — `escalated`;
- иначе при ≥ 3 голосах и взвешенном перевесе ≥ 2 — `accepted` (голос `both` даёт по 0,5 обоим вариантам);
- большинство детей не совпало с итогом — метка `children_prefer`.

Правила лиги проверяются только юнит-тестами на сервере:
- неделя пн–вс по Уфе;
- повышение — первые 5, понижение — последние 3;
- неделя закрывается лениво, при первом запросе новой недели.

**Готово, когда** `pnpm contracts:check && pnpm db:migrate && pnpm lint && pnpm typecheck` зелёные, а раннеры векторов подключены (до реализации — `todo`).

### Ч1. Демо-контент из открытых источников — агент с WebSearch и WebFetch, Д1–Д5

**Задание.** Юнит 1 «Знакомство»:
- уроки «Привет!», «Как тебя зовут?», «Моя школа», «Вежливые слова» и «Испытание места»;
- 6–8 упражнений на урок, около 30 слов и фраз;
- не меньше 6 дуэлей: русская фраза и **два разных засвидетельствованных** башкирских перевода.

Для примеров прототипа (строки 12–15 очереди) найти источники или заменить их найденными.

**Где искать** (наличие и условия проверить):
- Викисловарь ru и ba;
- Tatoeba;
- корпус AigizK на Hugging Face через API Datasets Viewer (`/search`, `/filter`) — один русский исходник с разными переводами лучше всего подходит для дуэли;
- открытые разговорники, например Викигид;
- учебники и пособия, выложенные издателями или органами образования РБ: автор, название, год, страница;
- онлайн-словари со ссылкой на статью.

Запросы — `curl` или TS-скрипт.

**Запрещено** (правила 6 и 15):
- башкирский текст из собственных знаний модели;
- «исправление» форм;
- аналогии с татарским;
- машинный перевод и LLM;
- Python.

Нет в источниках — единицы нет.

**Хранение:**
- `content/sources.yaml` — `id`, `title`, `url` или `edition`, `license` (как заявлено; юридическую оценку не делаем — правило 16), `accessed`;
- `content/course/ba-ru/course.yaml`;
- `content/course/ba-ru/units/01-ufa/lessons/*.yaml`;
- `content/corpus/duels/01-ufa.yaml`.

У каждой башкирской строки:
- `source: { ref, url | page, locator }` и `review: needs_native_review`;
- текст — посимвольная копия;
- если источник набирал двойниками (латинская schwa U+0259 вместо ә U+04D9, казахская U+049B вместо ҡ U+04A1), сохраняется `raw`, а в `ba` — результат `normalize` (правило 7).

В `docs/native-review-queue.md` — одна строка на файл контента; вердикт ставится в YAML. Это пометка, а не блокер.

**Проверка.** Скрипт `scripts/check-content.mjs` подключён в `pnpm lint` и проверяет:
- схему;
- кодовые точки;
- `normalize(ba) === ba`;
- ссылки на `sources.yaml`;
- строки очереди.

**Готово, когда** `node scripts/check-content.mjs` зелёный, объём набран и у каждой единицы открывается источник.

### Ч2. API: уроки, мёд, серия, лига (`content`, `learning`, `progress`, `competition`) — Д2–Д7

**Файлы:**
- четыре модуля;
- `matchAnswer` в `packages/bashkir-text`;
- `xp`, `streak`, `league` в `packages/domain-rules`;
- `pnpm --filter @teletau/api content:import` — идемпотентный, с версией контента.

**Операции:** все из таблицы Ч0, кроме `/corpus/*`. Голос в уроке передаётся в `ConsensusService.recordVote` (Ч3); до готовности Ч3 — заглушка интерфейса из `consensus/index.ts`.

**Готово, когда** зелёные `pnpm vectors` и `pnpm --filter @teletau/api test && pnpm --filter @teletau/api test:integration`. Интеграционные тесты покрывают:
- матрицу авторизации;
- урок 1 от `runs` до `complete` с мёдом и серией по векторам;
- повтор `attemptId` и `runId` без двойных начислений;
- закрытие недели лиги с подменёнными часами;
- чужой учитель на `progress` → 403.

### Ч3. API: дуэль и голоса по группам (`corpus`, `consensus`) — Д2–Д6

**Файлы:**
- два модуля;
- `duel-v0` в `packages/domain-rules`;
- `pnpm --filter @teletau/api corpus:import` — идемпотентный.

**`ConsensusService`:**
- `pickDuels(account, unit, n)` — без повторов своих голосов;
- `recordVote(tx, …)` — `voter_group` из типа аккаунта и ролей (подтверждённый учитель → `teacher`), пересчёт `item_state`, при решении — `pending` → `final` через `ProgressService`.

Операции `/corpus/*` из таблицы Ч0. Детям распределение голосов не показываем (защита от конформизма), только «Голос учтён».

**Готово, когда** зелёные `pnpm vectors` и интеграционные тесты:
- 3 голоса детей и 1 голос учителя → `accepted`, мёд согласных детей стал `final`;
- `UPDATE` и `DELETE` в `judgments` запрещены базой;
- пересчёт из журнала совпадает с `item_state`;
- ребёнок на `POST /corpus/judgments` → 403.

## 5. Самопроверка в облегчённом режиме

1. `pnpm typecheck && pnpm lint` — включая границы модулей, хардкод токенов и `check-content`.
2. `pnpm test && pnpm vectors && pnpm contracts:check && pnpm codegen:check`. Логика — через общие векторы (правило 2): `answer-check` («почти» на 9 парах букв), `xp`, `streak`, `consensus/duel-v0`. Лига — юнит-тестами с подменёнными часами.
3. `pnpm --filter @teletau/api test:integration` — матрица авторизации и неизменяемость `judgments`.
4. Один сквозной сценарий главного пути: `pnpm e2e` → `m2-demo.spec.ts`, при свободных портах 3000/3100/4000.
5. Итог: `bash scripts/verify.sh --skip-mobile`.

**До показа не делаем:**
- жюри-агенты;
- мобильные сборки и снапшоты (контракт меняется только аддитивно, вернёмся к ним в M6/M7);
- Lighthouse;
- полный аудит доступности.

## 6. Риски и вопросы к владельцу

**Блокирующие:**
1. **Точная дата показа — в Д7 или ближе к Д12?** От неё зависит, где режем объём (§4).
2. **Публичный HTTPS-адрес для Mini App.** Telegram открывает Mini App только по HTTPS: нужна ВМ в российском облаке с доменом и TLS или туннель на время показа. Кроме того, бот в @BotFather с кнопкой меню. Без этого Mini App показываем как `/miniapp` в браузере. Остальную веху вопрос не блокирует.

**Не блокируют:**
- **Контент.** Носитель не нужен. Тексты взяты из открытых источников с пометкой `needs_native_review`. Если для дуэли не найдётся двух переводов, используем синонимы из словарной статьи.
- **Telegram Web на компьютере** открывает Mini App во фрейме, и сторонняя cookie BFF может блокироваться (Safari). Показываем на телефоне.
- **Замедление Telegram в РФ** (`docs/08` §8). Запасной путь — та же ссылка в браузере.
- **Правила дуэли v0 и числа мёда** — стартовые, калибруем в M4 и на пилоте. Голоса неизменяемы, поэтому пересчёт возможен.
