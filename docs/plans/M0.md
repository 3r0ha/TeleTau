# План вехи M0 — Фундамент

Источник объёма: `docs/09-roadmap.md` §2 M0. Жюри гейта: `jury-architecture`, `jury-qa` (матрица `docs/10-jury-loop.md` §3), порог — средняя ≥ 7,5.

## Задачи

### T1. Монорепозиторий и соглашения
- `package.json` (workspaces, скрипты), `pnpm-workspace.yaml`, `turbo.json`, `tsconfig.base.json` (strict), ESLint (flat config + typescript-eslint), Prettier, `.editorconfig`, `.gitignore`, `.nvmrc`, `.env.example`.
- **Готово, когда:** `pnpm install` без ошибок; `pnpm lint` и `pnpm typecheck` зелёные по всем пакетам.

### T2. Общие данные и тест-векторы
- `contracts/shared/bashkir-homoglyphs.json` — единственный источник таблицы замен (с обоснованием каждой записи).
- `contracts/test-vectors/bashkir-text/{normalize,fold}.json` + `README.md` (формат векторов).
- **Готово, когда:** векторы покрывают все 9 особых букв (оба регистра), латинские и тюркские подстановки, контекст «только в кириллическом слове», комбинирующую седиль, пробелы, неизменяемые русский и латинский тексты.

### T3. `packages/bashkir-text` (TS) + кодогенерация таблиц для Swift и Kotlin
- `normalize()`, `fold()`, `toComparable()`; таблица импортируется из `contracts/shared`.
- `scripts/codegen.mjs` генерирует `Homoglyphs.generated.swift` и `Homoglyphs.generated.kt` в iOS- и Android-модули; `pnpm codegen:check` падает, если сгенерированное устарело.
- **Готово, когда:** все векторы проходят в vitest.

### T4. `packages/design-tokens`
- Токены в формате W3C DTCG (цвета светлой и тёмной темы, отступы, радиусы, шрифтовая шкала, длительности) → Style Dictionary 5 → `build/css/tokens.css`, Swift (`ios/.../TeleTauTokens.generated.swift`), Kotlin (`android/.../TeleTauTokens.generated.kt`).
- Проверка контраста WCAG для пар текст/фон в обеих темах (тест).
- `scripts/check-hardcoded-colors.mjs` — запрет hex/rgb-цветов вне сгенерированных файлов.
- **Готово, когда:** `pnpm tokens:check` зелёный; сгенерированные файлы актуальны.

### T5. `packages/contracts`
- `openapi.yaml` (3.1): `GET /api/v1/health`, схема `Problem` (RFC 9457).
- Генерация TS-типов (`openapi-typescript`), линт спецификации (Redocly), проверка ломающих изменений против `openapi.baseline.yaml` (oasdiff в Docker; без Docker — пропуск с предупреждением), проверка актуальности сгенерированного.
- **Готово, когда:** `pnpm contracts:check` зелёный.

### T6. Каркасы приложений (TS)
- `apps/api` — NestJS 12 (ESM) + Fastify: конфиг через zod, `GET /api/v1/health` (Postgres и Valkey, 503 при отказе), ошибки RFC 9457, Drizzle + первая миграция (расширения `vector`, `pg_trgm`, схема `pii`, collation `ba_tailored`), границы модулей — собственный скрипт `scripts/boundaries.mjs` с тестами (dependency-cruiser не работает на Node 25).
- `apps/web`, `apps/console` (порт 3100: 3001 занят) — Next.js 16: стартовая страница на токенах, шрифты Golos Text и Nunito (`cyrillic-ext`), тест-строка башкирских букв, светлая и тёмная темы.
- `apps/ai-gateway` — Fastify: `/health`, интерфейс провайдера + мок.
- `apps/workers` — BullMQ: подключение к Valkey, тестовая очередь.
- `apps/bot` — канально-независимое ядро (сценарий `/start`) + адаптер Telegram (grammY); без токена — работает вхолостую без падения.
- **Готово, когда:** у каждого приложения есть хотя бы один тест; всё собирается.

### T7. `apps/ml-worker` (TypeScript)
- Каркас сервиса пакетных расчётов: `/health`, тест. Dawid–Skene, Bradley–Terry и симулятор — в M4. **Никакого Python** (решение владельца).
- **Готово, когда:** тест и сборка зелёные.

### T8. Локальное окружение
- `docker-compose.yml` с healthcheck; `pnpm dev` = `docker compose up -d --wait` + миграции + все приложения через turbo.
- **Готово, когда:** одна команда поднимает всё, а `curl :4000/api/v1/health` возвращает 200 с `postgres: ok`, `valkey: ok`.

### T9. iOS (делегируется субагенту)
- `ios/project.yml` (XcodeGen), приложение `TeleTau` (iOS 17+, SwiftUI) со стартовым экраном на токенах.
- Swift Package `ios/Packages/TeleTauCore`: таргеты `BashkirText` (порт normalize/fold на сгенерированной таблице), `DesignSystem` (сгенерированные токены + компоненты стартового экрана); тесты: векторы + рендер стартового экрана в PNG (светлая и тёмная темы) через `ImageRenderer` на macOS.
- **Готово, когда:** `swift test --package-path ios/Packages/TeleTauCore` зелёный (векторы + снапшоты); приложение собирается под SDK симулятора. Без рантайма симулятора Xcode 26 отклоняет любой `-destination`, поэтому сборка — по таргету: `xcodebuild build -target TeleTau -sdk iphonesimulator CODE_SIGNING_ALLOWED=NO`.

### T10. Android (делегируется субагенту)
- Gradle 9.8.2 (wrapper), version catalog, convention-плагин; модули `:app` (Compose, стартовый экран на токенах), `:core:bashkirtext` (Kotlin/JVM, порт на сгенерированной таблице), `:core:designsystem` (сгенерированные токены + тема Compose).
- **Готово, когда:** `./gradlew :core:bashkirtext:test :app:assembleDebug` зелёный; по возможности — снапшот стартового экрана (Roborazzi/Paparazzi) в обеих темах.

### T11. CI и паритет с локальной проверкой
- `.github/workflows/ci.yml`: jobs `node`, `ios` (macOS), `android`, `secrets` (gitleaks).
- `scripts/verify.sh` — те же проверки локально (для самопроверки и жюри QA).

### T12. Документация
- ADR 0001–0013 в `docs/adr/`, раздел «Команды» в `CLAUDE.md`, `docs/demo/M0.md`, обновление `docs/STATUS.md`.

## Критерии приёмки M0 (проверяемые)

1. `pnpm install && pnpm dev` (при запущенном Docker) поднимает Postgres, Valkey, ClickHouse, MinIO (healthy) и приложения; `GET http://localhost:4000/api/v1/health` → 200, `checks.postgres = ok`, `checks.valkey = ok`; web — `http://localhost:3000`, console — `http://localhost:3100`.
2. `scripts/verify.sh` зелёный: lint, typecheck, unit-тесты, векторы TS, `contracts:check`, `tokens:check`, `codegen:check`, сборка TS-приложений.
3. Один и тот же набор векторов `bashkir-text` проходит в TS, Swift и Kotlin.
4. iOS: пакет проходит `swift test`, приложение собирается под SDK симулятора, стартовый экран отрендерен в PNG в обеих темах.
5. Android: `:core:bashkirtext:test` и `:app:assembleDebug` зелёные.
6. В коде приложений нет цветов вне дизайн-токенов (проверка скриптом).
7. ADR 0001–0013 на месте, `CLAUDE.md` содержит реальные команды.

## Риски и открытые вопросы
- **Рантайм iOS-симулятора не установлен** (~8 ГБ). Для M0 не блокирует; к M6 нужен (задача владельца или скачивание с разрешения).
- Совместимость AGP 9.5 и Gradle 9.8 с локальным JDK 27 — снимается toolchain JDK 21.
- Git-репозитория нет. CI-файл готовится, но проверяется локально через `scripts/verify.sh`. Инициализация git и пуш — по решению владельца.
- Дедлайн хакатона не известен (вопрос задан владельцу) — на M0 не влияет.
