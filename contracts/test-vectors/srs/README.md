## `fsrs6.json` (v1) — `fsrsReplay({ reviews })`

`reviews` — повторения слова по порядку: `{ on: "ГГГГ-ММ-ДД" (сутки по Уфе), rating: 1 | 2 | 3 | 4 }`
(1 Again, 2 Hard, 3 Good, 4 Easy). → `{ steps: [...] }` — состояние после каждого повторения:
`{ elapsedDays?, retrievability?, stability, difficulty, intervalDays, dueOn, reps, lapses }`. У первого повторения
(знакомство) `elapsedDays` и `retrievability` нет. Числа с плавающей точкой (`retrievability`, `stability`, `difficulty`)
сравниваются с допуском `tolerance` = 1e-6, остальное — точно.

Обозначения: G — оценка, t — `elapsedDays` (разность дат по Уфе), decay = −w₂₀, factor = 0,9^(1/decay) − 1.

1. **Извлекаемость** перед повторением: R(t, S) = (1 + factor · t / S)^decay. R(S, S) = 0,9.
2. **Знакомство** (первое повторение): S₀ = w[G−1]; D₀(G) = w₄ − e^(w₅·(G−1)) + 1, ограничено [1; 10].
3. **Трудность** при каждом следующем повторении: ΔD = −w₆ · (G − 3); D′ = D + ΔD · (10 − D) / 9 (линейное затухание);
   D″ = w₇ · D₀(4) + (1 − w₇) · D′ (возврат к среднему; D₀(4) — **без** ограничения, отрицательное); ограничено [1; 10].
4. **Устойчивость**, t > 0:
   - G ≥ 2 (вспомнил): S′ = S · (e^w₈ · (11 − D) · S^(−w₉) · (e^(w₁₀·(1 − R)) − 1) · h · b + 1), h = w₁₅ при Hard (иначе 1),
     b = w₁₆ при Easy (иначе 1);
   - G = 1 (забыл): S′ = min(w₁₁ · D^(−w₁₂) · ((S + 1)^w₁₃ − 1) · e^(w₁₄·(1 − R)), S / e^(w₁₇·w₁₈)).
   В формулах — D **до** обновления (шаг 3).
5. **Тот же день**, t = 0: SInc = e^(w₁₇·(G − 3 + w₁₈)) · S^(−w₁₉); при G ≥ 2 SInc = max(SInc, 1); S′ = S · SInc.
   Условие G ≥ 2 — как на странице «The Algorithm» и в `py-fsrs` (в `fsrs-rs` — G ≥ 3; на векторах это видно только в `f011`).
6. S′ ограничивается [0,001; 36 500].
7. **Интервал**: I = S / factor · (r^(1/decay) − 1) (при r = 0,9 — ровно S); округление до целого (половина — вверх),
   не меньше 1 и не больше 36 500 дней. **Срок** `dueOn` = `on` + I.
8. `reps` — сколько всего повторений; `lapses` — сколько из них, кроме первого, с G = 1.

## `rating.json` (v2) — `ratingFromVerdicts({ verdicts, hinted? })`

Оценку ставит не ученик, а проверка ответа (вердикты — `answer-check`): `correct` и `typo` → 3 (Good), `almost` → 2 (Hard),
`wrong` → 1 (Again). Из нескольких упражнений со словом в одном забеге — худшая; слово было в уроке без своего упражнения
(пустой список) → 3. Easy (4) автоматически не ставится. Засчитывается только **первая** попытка упражнения в забеге.

v2 (подсказки к условию, `AttemptRequest.hintsUsed`): `hinted[i]` — к упражнению `verdicts[i]` до ответа открывали
подсказку. Засчитанный ответ (`correct`, `typo`, `almost`) с подсказкой — не выше 2 (Hard): мёд и точность за него
начисляются как обычно, но слово вернётся в повторение раньше; `wrong` с подсказкой — 1. Нет `hinted` или `false` —
как в v1 (случаи r001–r007 не изменились).

## `status.json` (v1) — `srsStatus({ dueOn, today })`

Статус слова в «Моём словаре»: `review` («пора повторить»), если `today` ≥ `dueOn` (даты по Уфе), иначе `learned` («выучено»).

## Когда слово попадает в повторение (сервер, модуль learning)

- Слово — строка из `new_words` урока; ключ — слова `answerTokens` из `bashkir-text` через пробел (регистр и пунктуация
  не важны: «Сәләм!» и «Сәләм.» — одно слово).
- При завершении урока (`lesson`, `place_test`) каждое его слово без карточки получает карточку: знакомство (шаг 2) с оценкой
  по `rating.json`. Повтор урока карточки не трогает.
- Повторение (`POST /reviews/runs`) — короткий урок из слов, срок которых наступил (`status.json`), до 8 слов, сначала
  самые просроченные. Первая попытка каждого упражнения обновляет карточку (шаги 1, 3–7).
