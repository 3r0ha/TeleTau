# streak — серия

Эталон — `packages/domain-rules` (`src/streak.ts`), раннер — `pnpm vectors`. Методика — `docs/02` §6 (школьный календарь — в M2b).

## `streak.json` (v1) — `computeStreak({ completions, now })`

→ `{ today, current, longest, freezes, extendedToday, frozenDays, weekStart, week }`

Серия **пересчитывается** из моментов завершения уроков (`completions`, RFC 3339 в UTC; порядок и повторы не важны) — отдельного
изменяемого состояния у неё нет.

1. **Сутки — по Уфе** (Asia/Yekaterinburg, UTC+5, без перехода на летнее время). День занятия — дата момента по Уфе.
   `today` — дата `now` по Уфе.
2. **Цель дня — 1 урок**: день активен, если в нём есть хотя бы одно завершение.
3. Проход по дням от первого активного дня до вчера включительно; `freezes` = 2 (старт), `current` = 0, `run` = 0:
   - день активен → `current` += 1, `run` += 1; если `run` = 7 → `freezes` = min(2, `freezes` + 1), `run` = 0
     («+1 за 7 дней подряд», не больше 2);
   - день не активен и `current` > 0: есть заморозка → `freezes` −= 1, день — в `frozenDays`, `run` = 0 (замороженный день
     серию не удлиняет и прерывает «7 дней подряд»); заморозки нет → `current` = 0, `run` = 0;
   - день не активен и `current` = 0 — ничего не тратится;
   - `longest` = max(`longest`, `current`) после каждого дня.
4. **Сегодня** не наказывается: если сегодня активен — тот же шаг «день активен» и `extendedToday` = true; иначе серия по вчера
   остаётся (`extendedToday` = false).
5. `weekStart` — понедельник недели, в которую попадает `today`; `week` — 7 статусов пн–вс: `future` (после сегодня),
   `done` (активен, в том числе сегодня), `today` (сегодня, ещё не активен), `frozen` (в `frozenDays`), иначе `missed`.
