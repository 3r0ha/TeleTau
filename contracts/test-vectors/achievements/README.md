# achievements — награды

Эталон — `packages/domain-rules` (`src/achievements.ts`), раннер — `pnpm vectors`. Методика — `docs/02` §6. Тексты наград
(название, что сделать, значок) отдаёт сервер (`GET /me/achievements`, `Achievement` в `openapi.yaml`); здесь — только
правила.

## `achievements.json` (v1) — `computeAchievements(input)`

→ массив из 12 наград в порядке набора: `{ id, earnedOn, progress, target }`.

Награды **пересчитываются** из истории ученика — отдельного состояния у них нет. Все даты — ГГГГ-ММ-ДД по суткам Уфы.

### Вход

| Поле | Что это |
|---|---|
| `today` | Сегодня по Уфе |
| `lessons` | Каждое завершение урока или «Испытания места» (`lesson`, `place_test`; не «Помоги языку», не повторение, не испытание для перехода): `{ lessonId, on, firstAttempts }`, `firstAttempts` — вердикты первых попыток (`correct`, `almost`, `typo`, `wrong`, `recorded` — дуэль) |
| `skips` | Уроки, засчитанные сданным испытанием для перехода: `{ lessonId, on }` |
| `places` | Места курса по порядку: `{ id, lessons }`, `lessons` — уроки и «Испытание места» (без «Помоги языку») |
| `activeDays` | Дни занятий — те же, что у серии (`streak/`) |
| `goalDays` | Дни, когда выполнена цель дня (повторы не важны) |
| `words` | День, когда слово попало в «Мой словарь», — по одному на слово |
| `votes` | День каждого голоса в «Помоги языку» («Не знаю» — не голос) |

### Набор

| `id` | Правило | `target` |
|---|---|---|
| `first-lesson` | уроков в `lessons` | 1 |
| `perfect-lesson` | уроков без ошибок: в `firstAttempts` есть задание с проверкой (не `recorded`) и нет `wrong` («почти» и опечатка — не ошибка) | 1 |
| `streak-3`, `streak-7`, `streak-30` | дней подряд | 3, 7, 30 |
| `goal-7` | разных дней в `goalDays` | 7 |
| `words-10`, `words-50` | слов в `words` | 10, 50 |
| `first-vote`, `votes-10` | голосов в `votes` | 1, 10 |
| `first-place` | пройденных мест | 1 |
| `all-places` | пройденных мест | все места с уроками, не меньше 1 |

### Правила

1. **Счётные награды** (всё, кроме серии): `earnedOn` — день `target`-го события по возрастанию дней (`null`, если событий
   меньше); `progress` = min(`target`, число событий).
2. **Место пройдено**, когда пройден каждый его урок — уроком (`lessons`) или испытанием для перехода (`skips`); день урока —
   самое раннее из них, день места — самый поздний из дней его уроков. Места без уроков не считаются.
3. **Серия** — по правилам `streak/README.md` (заморозки, обнуление). `earnedOn` — первый день занятий, в который серия
   дошла до `target` (замороженный день серию не удлиняет). У ещё не полученной награды `progress` — текущая серия на `today`
   (не больше `target`); полученная остаётся полученной, `progress` = `target`.
4. Полученная награда остаётся полученной: история только растёт. Исключение — `all-places`: цель — места **текущего** курса,
   новое место с уроками снова делает её неполученной, пока его не пройдут.
5. Порядок и повторы во входных массивах не важны (кроме `words` и `votes`: там каждый элемент — отдельное слово или голос).

### Как сервер собирает вход

`lessons` и `goalDays` — завершённые забеги ученика (`goalDays` — дни, где итог забега выполнил цель дня); `skips` и
`activeDays` — модуль progress; `words` — первая запись журнала повторений каждого слова, которое есть в словаре курса;
`votes` — голоса в журнале мёда. «Новые» награды итога урока — разница между наградами до и после завершения забега (голоса
этого забега в «до» не входят).
