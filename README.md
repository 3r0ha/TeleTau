# 🐝 ТелеТау — Башкирская языковая школа

Геймифицированная платформа изучения башкирского языка для школ Республики Башкортостан.
Каждый урок одновременно учит ученика и пополняет открытую базу подтверждённых переводов рус↔баш:
базу согласовывает сообщество (ученики, носители, учителя), проверяют эксперты, а потребляют
школы, Фонд башкирского языка, разработчики и исследователи.

### Креды для демонстрации

Стенд в демо-режиме: письма не отправляются, код из «письма» — всегда **0000**, для сотрудников
шаг TOTP отключён. Персональных данных детей в демо-мире нет — только номер места и псевдоним.

| Кто | Как войти |
|---|---|
| **Учитель** | `teletau.study/teacher/login` → `teacher@demo.teletau.local` → код **0000**. Класс **5 «Б»** Демо-школы № 1 |
| **Ученик (новый)** | `teletau.study` → «У меня есть карточка или код» → код класса **000-000** → выбрать ник → заявку подтверждает учитель (страница 5 «Б», баннер «ученик ждёт») |
| **Ученик (демо-карточка)** | QR-карточка демо-ученика №07 «Смелая пчела» — камера на `/student` |
| **Министерство** | `console.teletau.study/login` → `ministry@demo.teletau.local` → код 0000 → раздел «Республика» |
| **Фонд башкирского языка** | так же, `fund@demo.teletau.local` → раздел «Словарь для Фонда» (выгрузка CSV) |
| **Модератор** | `moderator@demo.teletau.local` — заявки учителей |

Фоновые аккаунты (`teacher2@`, `adult1…@`, `region1…12@`) — не входить: их голоса уже в дуэлях.

### Публичное API — без регистрации

```sh
curl https://api.teletau.study/api/v1/public/dictionary                  # словарь JSON (ТЗ §5)
curl "https://api.teletau.study/api/v1/public/dictionary?format=csv"     # CSV для Excel («;», BOM)
curl "https://api.teletau.study/api/v1/public/dictionary?status=expert_review"  # только проверено носителем
curl "https://api.teletau.study/api/v1/public/leaderboard?period=week"   # доска почёта школ и классов (ТЗ §4.5)
curl https://api.teletau.study/api/v1/public/phrase-of-day               # фраза дня
```

Выгрузка — те же принятые пары, что для Фонда, но без голосов по группам и без персональных данных.
Языковые пары: башкирский ← русский (`ba-ru`) и башкирский ← казахский (`ba-kz`); интерфейс —
на русском, башкирском и казахском (переключатель в шапке лендинга и в настройках профиля).

## 📱 Мобильные приложения

Нативные клиенты ученика — не обёртка над сайтом, а полноценные приложения:

- **Android** (Kotlin, Jetpack Compose) — тропа и уроки, «Мой словарь», лига и **доска почёта школ**
  (день/неделя/месяц/год), **фраза дня** на стартовом экране, озвучка курса, звук ответов.
  APK ставится с кнопки «Скачать для Android» на лендинге: https://teletau.study/teletau.apk
- **iOS** (Swift 6, SwiftUI) — тропа, уроки с озвучкой, словарь, лига.

Вход — по QR-карточке учителя или личной карточке «Учусь сам» (камера сканирует прямо в приложении),
без почты и персональных данных. API тот же, что у веба, — контрактом OpenAPI и кодогенерацией.

## Что здесь особенного

- **Двойная ценность каждого действия** — урок учит и создаёт общественное благо: открытый корпус переводов; ученик видит свой вклад («твой вариант вошёл в словарь»).
- **Честный консенсус** — дуэли «Какой перевод лучше?», голоса взвешиваются по группам (дети/взрослые/учителя), спорные пары уходят экспертам; у каждой пары — «карточка происхождения».
- **Публичная витрина** — словарь без регистрации (JSON/CSV), фраза дня на сутки для всех, доска почёта: компактный топ-3 на лендинге, полная топ-10 за день/неделю/месяц/год — в приложении ученика — только агрегаты, малые группы скрыты.
- **Методика, а не геймификация ради геймификации** — FSRS-6 (интервальное повторение), адаптивный подбор, серия-«соты», квест класса, лиги медоносов.
- **Весь курс озвучен** — у каждого слова есть «Послушать»: записи носителей (Wikimedia Commons / Lingua Libre), а строкам без записи синтезирована озвучка (Silero, башкирский) — с честной пометкой происхождения, синтез не выдаётся за носителя.
- **Приватность по умолчанию** — рейтинги только целых групп, малые классы скрыты; напоминания планируем считать на устройстве, без слежки за профилем.
- **Везде, где есть ученик** — веб, Mini App внутри Telegram, бот с ежедневным заданием, нативные iOS/Android с офлайном для сёл со слабой связью.

## Быстрый старт (локально)

```sh
pnpm install          # Node ≥ 24, pnpm ≥ 9
pnpm demo:reset       # Docker (Postgres, Valkey, ClickHouse, MinIO) + миграции + демо-мир
pnpm dev              # веб :3000, API :4000, консоль :3100, бот
```

Локально вход тот же, но сотрудникам после кода 0000 нужен TOTP — секреты в [`apps/api/data/README.md`](apps/api/data/README.md).

Полная самопроверка (CI-паритет: типы, линтеры, тесты, контракты, сборки, iOS/Android, e2e) — `bash scripts/verify.sh`.

| Каталог | Что там |
|---|---|
| `apps/api` | NestJS: identity, org, learning, consensus, corpus, progress, telegram, ministry, assignments |

| `packages/*` | дизайн-токены, UI, сессия, башкирский текст (нормализация), FSRS, доменные правила |
| `content/` | Курс и корпус дуэлей (открытые источники, YAML + импорт) |
