# ТелеТау — Башкирская языковая школа

> Рабочее название бренда, требует проверки носителем и Фондом башкирского языка.

Геймифицированная платформа изучения башкирского языка для школ Республики Башкортостан. Каждый урок одновременно учит ученика и пополняет открытую базу подтверждённых переводов рус↔баш. Базу согласовывает сообщество (ученики, носители, учителя) и проверяют эксперты, а потребляют её через API школы, Фонд башкирского языка, разработчики и исследователи.

**Заказчик:** Министерство просвещения Республики Башкортостан
**Каналы:** веб-платформа · нативные iOS (Swift/SwiftUI) и Android (Kotlin/Jetpack Compose) · Telegram-бот и Telegram Mini App
**AI:** GigaChat
**Цель:** релиз 1.0 — полноценный продукт, не MVP
