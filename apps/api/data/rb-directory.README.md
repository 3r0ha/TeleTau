# Справочник районов и школ Республики Башкортостан

Учитель при регистрации выбирает **район / городской округ** и **школу** из этого справочника
(`districts`, `schools` в модуле `org`, см. `docs/07-data-and-api.md` §1.1). Данные собраны из
официальных открытых источников скриптами в `scripts/` и воспроизводимо обновляются (раздел
«Как обновлять»).

| Файл                              | Что внутри                                                                                             |
| --------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `rb-districts.csv`                | 54 муниципальных района и 9 городских округов РБ с ОКТМО                                               |
| `rb-schools.csv`                  | Общеобразовательные организации РБ (юрлица) и их филиалы, с привязкой к району по ОКТМО                |
| `scripts/fetch-sources.mjs`       | Скачивание сырых данных во временный каталог (`$TMPDIR/teletau-rb-directory`, в репозиторий не попадают) |
| `scripts/build-rb-directory.mjs`  | Разбор, фильтрация, сопоставление школ с районами, запись CSV и блока статистики ниже                  |
| `scripts/verify-rb-directory.mjs` | Проверки целостности (см. «Проверки»)                                                                  |
| `scripts/lib.mjs`                 | Общие функции: HTTP, чтение ZIP/ZIP64 (в т. ч. по HTTP Range), потоковый разбор XML, CSV по RFC 4180   |

Скрипты — Node.js (≥ 22, проверено на 24 и 26), без зависимостей и без Python.

## Формат

Оба файла: UTF-8 без BOM, разделитель — запятая, перевод строки — CRLF, экранирование по RFC 4180
(поле с запятой, кавычкой или переводом строки — в двойных кавычках, кавычка внутри удваивается).
Пустое значение — пустое поле. Unicode NFC.

- **Министерство просвещения РБ** (<https://education.bashkortostan.ru/opendata/>) — единственный набор

  `name_ba` взяты из башкирской Википедии.
- **OpenStreetMap** — не понадобился: официальные источники покрыли все 63 района.

Root CA»). Ничего в систему не устанавливается: корневой и промежуточные сертификаты кладутся в
PEM-файл вне репозитория и передаются Node через `NODE_EXTRA_CA_CERTS` (см. «Как обновлять»).

## Методика

### Районы

1. Из ГАР берутся действующие (`ISACTUAL=1`, `ISACTIVE=1`) объекты уровня 3 «Муниципальный район»
   региона 02: тип `м.р-н` → `municipal_district`, `г.о.` → `urban_okrug`. ОКТМО — текущее значение
   параметра 7 (`ENDDATE=2079-06-06`). Получилось 54 + 9 = 63; ни одного муниципального округа (реформа
   2025 г. Башкортостан пока не затронула — при её появлении скрипт упадёт на неизвестном типе).
2. Перечень сверяется со списком на портале РБ (п. 3) — расхождений нет.
3. `name_ba` — заголовок статьи ba.wikipedia из Wikidata по совпадению ОКТМО; уточнение в скобках
   («(Башҡортостан)») отбрасывается. Каждая буква проверяется по белому списку (кириллица + ә ө ү ғ ҡ ң ҙ ҫ һ):
   латинские и татарские подстановки (ə U+0259, җ U+0497, қ U+049B, h…) — ошибка.

### Школы

1. Потоково разбирается XML реестра (1 ГБ, ~107 тыс. свидетельств). Берутся свидетельства с
   `RegionCode=02` (или организацией в РБ) и статусом **«Действующее»**.
2. Школа = в действующих приложениях есть программа начального, основного или среднего общего
   образования **и** в наименовании есть «школ / гимнази / лице(й|я) / интернат / кадетск /
   общеобразовательн» **и** нет признаков профессиональной или высшей организации («профессиональное
   образовательное», «высшего образования», «колледж», «техникум») или ИП. Так отсекаются колледжи и
   вузы со школьными программами, «Ишимбайское специальное учебно-воспитательное учреждение закрытого
   типа» и ИП; лицеи и гимназии при вузах («Гимназия № 82 УГНТУ») остаются.
3. Юрлица дедуплицируются по ИНН (при нескольких действующих свидетельствах — более позднее).
4. Филиалы — приложения с `IsForBranch=1`; филиал включается, если хотя бы одно его приложение
   действующее. Дубли (район + наименование) отбрасываются.
5. **Привязка к району** (порядок, первое сработавшее правило записывается в `oktmo-by`):
   1. `address-district` — в адресе назван муниципальный район («Кугарчинский район», «р-н Абзелиловский»);
   2. `address-city` — в адресе назван город: городской округ (Уфа, Сибай…) или город районного
      подчинения (Белебей → Белебеевский район) — по ОКТМО города в ГАР;
   3. `address-settlement` — населённый пункт адреса однозначен в РБ по ГАР (с учётом пп. 1–2);
   4. `name-district`, `name-okrug`, `name-city`, `name-settlement` — то же по официальному
      наименованию («…муниципального района Илишевский район…», «…городского округа город Уфа…»);
   5. `parent-district` — филиал с неоднозначным адресом, если один из кандидатов — район головной
      организации.

   Сравнение — без учёта регистра и «ё/е» (в реестре встречаются «Г САЛАВАТ», «г, Уфа»,
   «Башкортостан.г. Октябрьский»). Внутригородские районы Уфы и Стерлитамака («Октябрьский район»)
   не путаются с муниципальными: в справочнике районов их нет.

6. Все независимые подсказки (район, город, однозначный населённый пункт в адресе и в названии)
   сравниваются с выбранным районом; расхождения пишутся в `report.json` для ручной проверки. В
   текущей выгрузке таких записей 7, все проверены вручную и привязаны верно: «село Уфимский»
   Хайбуллинского района даёт ложную подсказку «Уфимский район» (6 записей); филиал в д. Аралбаево
   Кугарчинского района (так в адресе и в названии головной школы) — в ГАР деревня с таким именем есть
   только в Зилаирском районе.

филиалы (488) в официальной цифре не учитываются.

## Известные пробелы

- `category`, `bashkir_medium`, `name_ba` у школ — пусто: ни в одном использованном источнике этих
  признаков нет. Нужен официальный перечень Минпросвещения РБ (задача владельца в
  `docs/14-owner-tasks.md`).
- Нет школ без государственной аккредитации (новые и некоторые частные) — см. сверку выше.
- Статус в реестре может отставать от жизни: ликвидированная школа может ещё числиться
  «Действующей», а свежий филиал — отсутствовать. Реестр обновляется ежедневно, данные вносит
  Минпросвещения РБ.
- Наименования и адреса — как в реестре: опечатки («общеобразовательнаое»), слитные слова
  («РеспубликаБашкортостан,Бакалинскийрайон»), одно наименование ПРОПИСНЫМИ. Не исправлялись, чтобы
  не расходиться с официальным реестром.
- В текущей выгрузке у 2 пар разных юрлиц совпадают адреса (вероятно, ошибка ввода в реестре) —
  оставлены как есть. Совпадений адреса филиала с адресом другой (не головной) школы, которые
  указывали бы на «зависшую» ликвидированную школу, не найдено.
- `name_ba` районов — из башкирской Википедии, не из официального документа; требует проверки
  носителем (`docs/native-review-queue.md`).

## Проверки

`node apps/api/data/scripts/verify-rb-directory.mjs` (код возврата 1 при ошибке):

- заголовки, CRLF, отсутствие BOM, баланс кавычек и число полей в каждой записи (RFC 4180), NFC;
- ОКТМО районов: формат, уникальность, соответствие `kind`; 54 + 9 (иначе предупреждение);
- у каждой школы `district_oktmo` есть в `rb-districts.csv`; районы без школ — предупреждение;
- нет дублей ИНН и пар «район + наименование» (без учёта регистра и ё/е); ИНН — контрольная сумма;
- `name_ba` — только кириллица и башкирские буквы правильных кодовых точек;
- в наименованиях и адресах нет e-mail, телефонов и ИП.

## Как обновлять

```sh
# 1. Сертификаты НУЦ Минцифры — во временный файл (вне репозитория, ничего не устанавливается)
CA="$TMPDIR/teletau-rb-directory/russian-trusted-ca.pem"; mkdir -p "$(dirname "$CA")"
curl -s https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt  > "$CA"; echo >> "$CA"
curl -s https://gu-st.ru/content/lending/russian_trusted_sub_ca_pem.crt   >> "$CA"; echo >> "$CA"
curl -s http://nuc-cdp.digital.gov.ru/cdp/subca_ssl_rsa2024.crt | openssl x509 -inform der >> "$CA"

# 2. Скачать (≈370 МБ, 1–3 мин), собрать, проверить
NODE_EXTRA_CA_CERTS="$CA" node apps/api/data/scripts/fetch-sources.mjs   # можно частями: raoo gar portal wikidata
node apps/api/data/scripts/build-rb-directory.mjs
node apps/api/data/scripts/verify-rb-directory.mjs
```

Каталог сырых данных переопределяется `TELETAU_RB_WORKDIR`. После сборки:

1. Просмотреть `$TMPDIR/teletau-rb-directory/report.json`: `unresolved` (школы без района — в CSV не
   попали), `conflicts` (подсказки расходятся с выбранным районом), `excluded` (отброшенные по
   наименованию). При новых случаях — поправить правила в `build-rb-directory.mjs`.
2. Если изменились `name_ba` районов — обновить строку в `docs/native-review-queue.md`.
3. Блок «Статистика выгрузки» выше перезаписывается сборкой автоматически.
